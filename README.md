# PhiChart Editor

Phigros 谱面渲染器 + 制谱器。仓库现状：**规格文档齐全 + 第一版渲染器（v1）可运行**。

## 快速开始（渲染器 v1）

在项目根目录启动静态服务器（浏览器模块与 `fetch` 需要 http 环境）：

```powershell
python -m http.server 8099
# 或
npx serve -l 8099
```

打开 <http://127.0.0.1:8099/index.html>，点左侧的**内置示例包**按钮（official / RPE 各一个）即可预览；
也可以「选择谱面包目录 / 选择 zip / 拖拽文件夹」加载自己的包。

- 快捷键：`空格` 播放/暂停、`←/→` ±5s、`R` 重开、`[` `]` 倍速、`N` `M` 音符宽度（默认 W/8，可调）。
- 范围：**只渲染关卡本体**（无开场/结束动画），自动游玩（音符落线即 Perfect）并实时计分。

## 目录结构

```
index.html / styles.css        渲染器页面与暗色 UI
src/core/                      内部统一模型、两套格式解析器、事件/时间/计分
src/render/                    Canvas2D 渲染后端与贴图处理
src/app/                       播放器、主循环与 UI 绑定
tools/                         谱面画像器、公式验证、渲染/HTTP 冒烟测试、贴图取色与测量
assets/                        音符/打击特效贴图与打击音效（提取自游戏）
packages/                      两个调试谱面包（official 与 RPE 各一）
```
