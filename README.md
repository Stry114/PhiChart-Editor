# PhiChart Editor

Phigros 谱面渲染器 + 制谱器。仓库现状：**规格文档齐全 + 第一版渲染器（v1）可运行**。

## 快速开始（渲染器 v1）

### 启动

**方式 A（Windows 一键，推荐）**：双击项目根目录的 `启动渲染器.cmd`。它会自动找到 Python、在 8099 端口起静态服务器、并打开浏览器（服务器日志就在那个窗口，Ctrl+C 结束）。

**方式 B（手动）**：在项目根目录执行任一条，然后打开 <http://127.0.0.1:8099/index.html>：

```powershell
python -m http.server 8099
# 或
npx --yes serve -l 8099 .
```

> 为什么需要服务器：页面用 ES 模块 + `fetch` 读取谱面包，浏览器在 `file://` 下会拦截这类请求。
> 直接双击 `index.html` 也能跑起来，但只能用「选择谱面包目录 / 选择 zip」的方式载入（见下）。

### 打开仓库里的两个测试包

服务器启动后，页面左侧「载入谱面」里有两个**内置示例包按钮**，点一下即可（会自动读取 `packages/` 下的谱面、音频、曲绘）：

| 按钮 | 包目录 | 谱面 | 规模 |
| --- | --- | --- | --- |
| 白复生 AT（official） | `packages/白复生 AT（official格式）` | `Chart_AT #3649.json`（25.8 MB） | 24 线 / 1156 音符 / 174 BPM / 161.7 s |
| 领土战争 AT（RPE） | `packages/领土战争AT（RPE格式）` | `29519800.json`（40.8 MB） | 24 线 / 1417 音符 / 8.1 万事件 / 140 BPM / 150.9 s |

其它载入方式（不受 `file://` 限制）：

- **选择谱面包目录** → 选 `packages/白复生 AT（official格式）` 或 `packages/领土战争AT（RPE格式）` 整个文件夹；
- **拖拽**：把包文件夹或 zip 直接拖到窗口里；
- **选择 zip 谱面包**：把包压成 zip 后选它（内置解压，无需第三方库）；
- **只选谱面 JSON**：只加载谱面本体（没有音乐/曲绘，用于快速看结构）。

打开后按 `空格` 播放；`←/→` 跳转 5s、`R` 重开、`[` `]` 倍速、`N` `M` 调音符宽度（默认 W/8）。

## 测试

```powershell
node tools/render-tests.mjs        # 解析 / 单位与公式 / 判定计分 / 父子线 / zip / info.csv（71 项）

node tools/http-smoke.mjs http://127.0.0.1:8099   # 页面/模块/示例包 URL（25 项，需先起服务器）
```

## 目录结构

```
index.html / styles.css        渲染器页面与暗色 UI
src/core/                      内部统一模型、两套格式解析器、事件/时间/计分
src/render/                    Canvas2D 渲染后端与贴图处理
src/app/                       播放器、主循环与 UI 绑定
tools/                         谱面画像器、公式验证、渲染/HTTP 冒烟测试、贴图取色与测量
assets/                        音符/打击特效贴图与打击音效（提取自游戏）
packages/                      两个调试谱面包（official 与 RPE 各一）
渲染效果图.png                  渲染结果参考图（与 docs/05 §4.2 的视觉常量对应）
```
