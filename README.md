# PhiChart Editor

Phigros 谱面的**制谱器与渲染器**：读取 official（游戏本体）与 RPE（Re:PhiEdit）两种格式，在浏览器里实时预览与编辑，并写回两种格式或保存为本编辑器的项目文件。

- 在线使用：<https://stry114.github.io/PhiChart-Editor/>
- 源码仓库：<https://github.com/Stry114/PhiChart-Editor>

纯静态资源、零构建步骤、无第三方运行时依赖：贴图与音效取自 `assets/`，其余全部是原生 ES 模块。

## 快速上手

1. 打开 <https://stry114.github.io/PhiChart-Editor/>，进入**编辑器**；
2. 在欢迎弹窗中载入内容：选择谱面包文件夹、选择谱面包 zip（或本编辑器的 `.pce.zip` 项目包），或填写元数据新建项目；也可把包直接拖入窗口；
3. 在时间轴上编辑音符与事件，用「纠错」页检查问题；
4. 在「导出」页执行**保存项目（内部格式）**，产出 `.pce.zip`。

谱面与音频只在本机浏览器内处理，不会上传到任何服务器；仓库不含第三方谱面包，使用自己的谱面即可。

| 页面 | 用途 |
| --- | --- |
| `index.html` | 开始页：只提供「编辑器 / 播放器」两个入口 |
| `edit.html` | 编辑器：制谱与实时预览 |
| `player.html` | 播放器：只播放与查看谱面 |

在线版与本地版是同一份代码，推送到 `main` 后由 GitHub Actions 自动发布。首次打开需加载全部贴图与字体；发布后的数分钟内浏览器可能仍持有旧缓存，强制刷新（`Ctrl+F5`）即可。

## 本地运行（离线 / 局域网）

在项目根目录启动静态服务器，再打开开始页：

```powershell
启动渲染器.cmd                        # Windows 一键：启动服务器并打开浏览器
python tools/dev_server.py            # 等价的手动方式（默认 8099）
python tools/dev_server.py --host 127.0.0.1   # 只允许本机访问
```

必须使用 `tools/dev_server.py`：`python -m http.server` 不发送缓存头，浏览器会启发式缓存 ES 模块与谱面 JSON，导致「页面已更新、部分模块仍是旧版」。开发服务器显式发送 `Cache-Control: no-store`。

服务器默认监听 `0.0.0.0`，启动时列出局域网地址（平板与手机可用同一地址打开）。整个项目目录对局域网可见，仅在可信网络中开启。

## 编辑器流程

### 载入

欢迎弹窗要求先选择一种载入方式，载入前编辑器不可操作，载入后弹窗自动关闭：

1. **打开文件夹包**：含谱面 JSON、音频与曲绘的目录；
2. **打开 zip 包**：谱面包 zip，或本编辑器保存的 `.pce.zip` 项目包；
3. **创建新项目**：填写全部元数据，并上传音频与背景图。

也可直接打开谱面 / 项目 JSON，或把包拖入窗口。

### 保存与自动保存

- 网页不写入磁盘、不上传内容：编辑结果只存在于内存与浏览器本地草稿；
- 「导出」页的**保存项目（内部格式）**是唯一的保存动作，产出 `.pce.zip`（含全部资源文件）；导出官谱 / RPE 属有损互操作，不是保存；
- 存在未保存修改时，「导出」标签页显示「未保存」角标，关闭或刷新标签页会被拦截提醒；
- 草稿：改动停止约 4 秒后，编辑器把项目格式（无损）gzip 压缩后写入浏览器本地，下次进入时可在欢迎弹窗中恢复。草稿仅是本机浏览器里的补救手段，不能替代保存：清除站点数据即丢失；保存项目成功后自动删除；音频等大文件不随草稿保存，恢复后可在「谱面总览」页重新上传。

### 谱面包

仓库不含谱面包，`packages/` 是自备目录（不在版本库内）。页面不依赖任何自带谱面，请使用自己的谱面。

## 功能

**编辑器**（`src/editor/`）

- 打开谱面包文件夹、zip 包、单个谱面 JSON，或本编辑器的项目文件；也可直接拖入窗口。
- 新建项目：填写全部元数据并上传音频与背景图。
- 谱面总览页：编辑全部元数据（曲名 / 曲师 / 谱师 / 曲绘师 / 难度 / ID / offset / **全局流速控制**），更换音频与曲绘；包内缺资源时在页内补齐，并随项目一起打包。「全局流速控制」（缺省 1.0）让整张谱面统一按倍率变快：所有音符与 Hold 的下落速度、所有 Hold 的长度都正好 ×k，预览与导出结果一致（判定时刻不变）。
- 时间轴：多轨自由组合、缩放与滚动、刻度与吸附、框选与拖动、添加与剪切工具、复制粘贴与撤销重做。
- 快速切线：按住 `Tab` 展开**全屏**圆环选线菜单（两圈 × 12 格 = 24 条线，钟表方向排布）。按**鼠标总位移方向**选线：位移较短为内圈、较长为外圈；松开 `Tab` 即把该线整组载入时间轴。超过 24 条线可用滚轮翻页。
- 详情面板：音符与事件的字段编辑；RPE 的 29 种缓动、缓动裁剪与自定义贝塞尔。
- 事件曲线页：直接拖动取值与贝塞尔控制点。
- 扩展（故事板）事件：RPE 的 `scaleX` / `scaleY` / `color` 可渲染、可编辑（结构树中单独成组，单击整组导入时间轴）；`color` 直接决定判定线颜色并支持渐变；本项目的（伪）3D 扩展 **`z`（Z 轴位移）** 与 **`theta`（下落面倾斜）** 同样可渲染、可编辑；其余扩展键保留写回但不渲染。
- 谱面相机（伪 3D 视角）：**谱面级**关键帧（`x` / `y` / `z` / `angle` 视角，按拍给值），在结构树顶部单独成组；相机不动时画面与没有相机逐像素一致。新增轨道会自动滚动到该轨并高亮。
- 纠错页：18 项模型检查（事件负时长、X/Y 位移不成对、音符重叠、相机取值与视角等），可点击跳转到出错的片段。
- 导出页（按用途排序）：保存项目（内部格式）、导出 RPE 谱、导出官谱，均为 zip 包。
- 预览快捷键：按住 `T` 试听（松开暂停并回到按下的时刻）、空格播放 / 暂停、`←/→` 跳转 5 秒、`R` 重开、`[` `]` 倍速。
- 未保存状态：导出标签页显示闪烁角标；关闭或刷新标签页会被拦截提醒；改动自动写入浏览器本地草稿。

**播放器**（`src/app/` + `src/render/`）

- 自动游玩并计分，渲染判定线、音符、Hold、42 帧打击特效与模糊背景；可载入谱面包文件夹 / zip 谱包 / 单文件谱面 JSON / 本编辑器的 `.pce.zip` 项目包；触屏设备另提供真实游玩模式（判定范围三档：垂直判定 / 轨道判定 / 全屏判定；多指判定、Good / Bad / Miss、Hold 允许换手与 80 ms 断连宽限、短于半拍的长条可随时松手）；曲终结算在音频完全播完后出现。
- 精准跳转、倍速、音符宽度调整；快捷键：空格播放 / 暂停、`←/→` 跳转 5 秒、`R` 重开、`[` `]` 倍速、`N` `M` 音符宽度。

**格式互操作**（`src/core/`）

| 方向 | 说明 |
| --- | --- |
| 导入 | official（formatVersion 1/2/3/3473）、RPE（含事件层、缓动、父子线、自定义线材质、扩展事件）、本编辑器的项目文件（编辑器与播放器都可直接载入 `.pce.zip`） |
| 导出 | RPE、official v3；多层事件合并、哨兵与首尾相接等引擎约束由导出器保证，有损之处逐条列在导出页；根对象首键写一句生成器声明 `generator`（「此谱面使用 PhiChart Editor 创建 · 在线地址」）；全局流速控制官谱侧烘焙进数值、RPE 侧写进 `META.speedMultiplier` |
| 项目文件 | `.pce.zip`：`project.json` + `info.txt` + 全部资源文件，无损保存事件层、缓动、未实现字段与元数据（含全局流速控制） |

## 项目结构

```
index.html / start.css         开始页（两个入口）
player.html / styles.css       播放器页面与暗色 UI
edit.html / editor.css         编辑器页面与暗色 UI
start.html                     旧地址跳转页
src/core/                      内部统一模型、两套格式解析与序列化、事件/时间/计分/元数据、zip 读写
src/render/                    Canvas2D 渲染后端与贴图处理
src/app/                       播放器：主循环、时钟、UI 绑定
src/editor/                    编辑器：欢迎弹窗、布局、时间轴、预览、结构树、详情面板、曲线、纠错、导出
src/ui/                        共用 UI：图标、跨页内容交接、项目生成器
src/start/                     开始页逻辑
tools/                         测试、真浏览器自检、开发服务器、谱面画像与测量工具
assets/                        音符与打击特效贴图、打击音效、界面图标
packages/                      自备谱面包目录（不在版本库内）
```

## 在线部署

线上地址：<https://stry114.github.io/PhiChart-Editor/>（源码仓库 <https://github.com/Stry114/PhiChart-Editor>）。

纯静态资源，`.github/workflows/pages.yml` 已配置为白名单部署：推送到 `main`（或在 Actions 中手动触发）后，工作流把应用本体拷入 `_site` 发布 —— 四个入口页面（`index.html` / `edit.html` / `player.html` / `start.html`）、三份样式、`src/`、`assets/` 与 `LICENSE`，并写入 `.nojekyll`；自备谱面包目录与 `docs/`、`tools/` 不进站点。仓库 Settings → Pages 的 Source 需为「GitHub Actions」。

Pages 对静态资源给的是分钟级缓存，更新发布后用户端可能需要强制刷新才能看到新版本。

`assets/` 的贴图与音效提取自游戏，是否公开请自行判断；如不公开，可在工作流中排除并在 `src/render/textures.js` 中替换为自制资源。

## 文案与文档风格

界面文案、提示、代码注释与文档统一遵循以下要求：

1. **简短、正式**：不使用口语、感叹与冗余修饰；单条提示不超过一句话。
2. **避免日志式输出**：界面不显示过程记录，只说明结果或当前状态。
3. **能删就删**：同一信息只出现在一处；重复的说明、显而易见的操作提示一律删除。
4. **信息优先**：需要用户决策时才提示，其余情况保持界面简洁。
5. **术语统一**：判定线、音符、事件层、事件块、谱面包、项目文件、速度（Y/s）。
6. **结论标依据**：文档与注释里的结论必须标注来源与可信度，规则见 [Phigros 文档](docs/Phigros文档.md) §0.1。

详细约定见 [项目文档](docs/项目文档.md) 的开发约定一节。
