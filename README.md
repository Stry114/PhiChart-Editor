# PhiChart Editor

Phigros 谱面的**制谱器与渲染器**：读取 official（游戏本体）与 RPE（Re:PhiEdit）两种格式，
在浏览器里实时预览、编辑，并写回两种格式或保存为本编辑器的项目文件。

纯静态资源、零构建步骤、无第三方运行时依赖：贴图与音效取自 `assets/`，其余全部是原生 ES 模块。

| 页面 | 用途 |
| --- | --- |
| `index.html` | 开始页：只提供「编辑器 / 播放器」两个入口 |
| `edit.html` | 编辑器：制谱与实时预览 |
| `player.html` | 播放器：只播放与查看谱面 |

## 功能

**编辑器**（`src/editor/`）

- 打开谱面包文件夹、zip 包、单个谱面 JSON，或本编辑器的项目文件；也可直接拖入窗口。
- 新建项目：填写全部元数据并上传音频与背景图。
- 时间轴：多轨自由组合、缩放与滚动、刻度与吸附、框选与拖动、添加与剪切工具、复制粘贴与撤销重做。
- 详情面板：音符与事件的字段编辑；RPE 的 29 种缓动、缓动裁剪与自定义贝塞尔。
- 事件曲线页：直接拖动取值与贝塞尔控制点。
- 纠错页：16 项模型检查（事件负时长、X/Y 位移不成对、音符重叠等），可点击跳转到出错的片段。
- 导出：官方格式 zip、RPE 格式 zip、内部项目 zip。

**播放器**（`src/app/` + `src/render/`）

- 自动游玩并计分，渲染判定线、音符、Hold、42 帧打击特效与模糊背景。
- 精准跳转、倍速、音符宽度调整；快捷键：空格播放/暂停、`←/→` 跳转 5 秒、`R` 重开、`[` `]` 倍速、`N` `M` 音符宽度。

**格式互操作**（`src/core/`）

| 方向 | 说明 |
| --- | --- |
| 导入 | official（formatVersion 1/2/3/3473）、RPE（含事件层、缓动、父子线、自定义线材质） |
| 导出 | official v3、RPE；多层事件合并、哨兵与首尾相接等引擎约束由导出器保证，有损之处逐条列在导出页 |
| 项目文件 | `.pce.zip`：`project.json` + `info.txt` + 全部资源文件，无损保存事件层、缓动与未实现字段 |

## 开始使用

在项目根目录启动开发服务器，再打开开始页：

```powershell
启动渲染器.cmd                        # Windows 一键：起服务器并打开浏览器
python tools/dev_server.py            # 等价的手动方式（默认 8099）
python tools/dev_server.py --host 127.0.0.1   # 只允许本机访问
```

> 请使用 `tools/dev_server.py`，不要用 `python -m http.server`：后者不发缓存头，
> 浏览器会启发式缓存 ES 模块与谱面 JSON，容易出现「页面已更新、某个模块还是旧的」。
> 开发服务器显式发送 `Cache-Control: no-store`。

服务器默认监听 `0.0.0.0`，启动时会列出局域网地址（平板 / 手机可用同一 URL 打开）。
注意整个项目目录都会对局域网可见，仅在可信网络中开启。

### 编辑器流程

进入编辑器后，欢迎弹窗要求先选择一种方式载入内容：

1. **打开文件夹包**：选择含谱面 JSON、音频与曲绘的目录；
2. **打开 zip 包**：谱面包 zip，或本编辑器保存的 `.pce.zip` 项目包；
3. **创建新项目**：填写全部元数据，并上传音频与背景图。

载入前编辑器不可操作；载入后弹窗自动关闭。也可直接打开谱面 / 项目 JSON，或把包拖入窗口。

### 谱面包

仓库**不含谱面包**：`packages/` 下的两份是第三方资源（合计 120+ MB），已从版本库移除。
页面本身不依赖它们，使用自己的谱面即可；需要跑依赖它们的测试时，按 `tools/samples.mjs`
里的目录名与文件名放入 `packages/`。

## 项目结构

```
index.html / start.css         开始页（两个入口）
player.html / styles.css       播放器页面与暗色 UI
edit.html / editor.css         编辑器页面与暗色 UI
start.html                     旧地址跳转页
src/core/                      内部统一模型、两套格式解析与序列化、事件/时间/计分/元数据、zip 读写
src/render/                    Canvas2D 渲染后端与贴图处理
src/app/                       播放器：主循环、时钟、UI 绑定
src/editor/                    编辑器：欢迎弹窗、布局、时间轴、预览、结构树、详情面板、曲线、纠错、导出
src/ui/                        共用 UI：图标、跨页内容交接、项目生成器
src/start/                     开始页逻辑
tools/                         测试、真浏览器自检、开发服务器、谱面画像与测量工具
assets/                        音符与打击特效贴图、打击音效、界面图标
packages/                      自备谱面包（第三方资源，不在版本库内）
```

## 开发与测试

```powershell
node tools/render-tests.mjs        # 解析 / 单位与公式 / 判定计分 / 序列化 / 项目格式 / zip
node tools/render-smoke.mjs        # 渲染路径 + 投影拾取 + Hold 几何 + 命中特效
node tools/app-smoke.mjs           # 播放器应用层
node tools/start-smoke.mjs         # 开始页
node tools/editor-smoke.mjs        # 编辑器（欢迎弹窗、时间轴、详情、曲线、纠错、导出）
node tools/browser-check.mjs       # 真浏览器自检（需要 Edge 或 Chrome）
node tools/http-smoke.mjs http://127.0.0.1:8099   # 页面 / 模块 / 贴图 URL（需先启动服务器）
```

依赖 `packages/` 的用例在缺包时自动跳过，并打印一行说明，不算失败。

离屏诊断工具（无需浏览器即可查看渲染结果）：`tools/render-frame.mjs`、`frame-sweep.mjs`、
`hold-sheet.mjs`、`fx-preview.mjs`、`probe-frame.mjs`。

## 部署

纯静态资源，直接把仓库推到 GitHub Pages 即可；`.github/workflows/pages.yml` 已配置为
白名单部署（只发布应用本体，排除 `packages/`）。在仓库的 Settings → Pages 中把 Source
设为 GitHub Actions 后，推送到 `main` 会自动发布。

`assets/` 的贴图与音效提取自游戏，是否公开请自行判断；如不公开，可在工作流中排除并在
`src/render/textures.js` 中替换为自制资源。

## 文案与文档风格

界面文案、提示与文档统一遵循以下要求：

1. **简短、正式**：不使用口语、感叹与冗余修饰；单条提示不超过一句话。
2. **避免日志式输出**：界面不显示过程记录（如「已给 3 号线新增事件层 2（X/Y/… 各一条默认事件」），
   只说明结果或当前状态。
3. **能删就删**：同一信息只出现在一处；重复的说明、显而易见的操作提示一律删除。
4. **信息优先**：需要用户决策时才提示，其余情况保持界面简洁。
5. **术语统一**：判定线、音符、事件层、事件块、谱面包、项目文件、速度（Y/s）。
6. 代码注释与提交信息同样遵循以上要求；文档中的结论必须标注来源与可信度。
