# 编辑器（阶段 3：编辑 UI）

> 状态：**可用的编辑骨架**。时间轴上的选择 / 拖动 / 参数编辑已经能改到内存模型、并立即反映到预览；
> **导出与保存还没做**（路线图阶段 1、2），所以目前改动只存在于内存里，刷新即丢。

编辑器和播放器是**同一个静态应用的两个入口**：

| 入口 | 文件 | 用途 |
| --- | --- | --- |
| 播放器 | `player.html` | 只播放/查看（渲染器 v1 的原有入口） |
| 编辑器 | `edit.html` | 编辑（本文档描述的对象） |
| 开始页 | `index.html` | **只有「编辑器 / 播放器」两个入口**（打开内容的功能都在编辑器内，站点根路径） |
| 欢迎弹窗 | 编辑器内 | 进入编辑器后先要求「打开文件夹包 / 打开 zip 包 / 创建新项目」（也支持拖放与 JSON），载入前编辑器是锁住的 |

三者共用 `src/core`（模型、解析、计时、缓动）与 `src/render`（Canvas2D 渲染）。

## 1. 界面结构

```
┌──────────────────────── 上半（高度默认 50%） ─────────────────────────┐
│ 左上工作区（宽度默认占 3/5）   │ 预览（实时渲染指针所在时刻）            │
│  标签：谱面总览 / Note 详情 /  │  ├ 画布铺满整块（没有顶栏）             │
│        Event 详情 / 事件曲线 / │  └ 播放条：播放 / ±5s / 重开 / 回滚 /     │
│        导出                   │     背景 / 音频 / 时间 / 倍速 / 性能统计  │
├──────────────────── 上下分隔条（拖拽改比例） ─────────────────────────┤
│ 左下工作区（宽度默认 1/4）│ 工具栏 │ 时间轴（主工作区）                   │
│  标签：结构树 / 纠错     │ 模式│动作│  工具条：拍号 / 吸附 / 刻度密度 /  │
│        （角标显示问题数）│    │    │    横向吸附与线数 / 缩放              │
└──────────────────────────────────────────────────────────────────────┘
```

**欢迎弹窗**（`src/editor/welcome.js`）：进入编辑器时若尚未载入谱面，遮罩锁住界面并要求选择
「打开文件夹包 / 打开 zip 包 / 创建新项目」（次要入口：打开谱面 / 项目 JSON、返回开始页）。
载入成功后自动关闭；期间不响应快捷键。

三个分隔条（`#ed-split-topleft` / `#ed-split-bottomleft` / `#ed-split-main`）的尺寸用 CSS 变量 + `localStorage` 记住（`src/editor/layout.js`）。

**默认比例**（没有存档 / 点了重置时用，按当前窗口宽度换算成像素）：

| 位置 | 比例 | 说明 |
| --- | --- | --- |
| 左上 : 右上 | **3 : 2** | 左上工作区 = 顶行宽度的 3/5（详情面板与曲线图需要宽度） |
| 左下 : 右下 | **1 : 3** | 左下工作区 = 底行**去掉两列工具栏后**宽度的 1/4 |
| 上 : 下 | **1 : 1** | 预览区 / 时间轴各占一半高度 |

> 存档带版本号（`v: 2`）：默认比例改过之后，旧存档会被**忽略一次**，否则用户永远看不到新默认。宽度上限是「右侧至少留 240px」，窗口很窄时会自动收住，不会把预览 / 时间轴挤没。

预览区**没有顶栏**（原来是「预览」标题 + 谱面信息行 + 判定线/音符/多押提示三个显示开关）：画布直接铺满。三个显示开关仍在代码里（`preview.opts.showLines / showNotes / multiHint`，默认全开），需要时再挂 UI。

**谱面总览页 = 元数据编辑页**：曲名 / 曲师 / 谱师 / 曲绘师 / 难度 / ID / offset 全部可改
（改动即时写入模型并标注来源「手动编辑」，offset 同步到播放时钟）；音频与曲绘可「更换…」，
包内缺资源时按钮为「上传…」，上传后写入 `meta.song` / `meta.background` 并登记为包内资源，
保存项目或导出 zip 时一起打包。页面**不提供载入按钮**：换存档请刷新页面，回到欢迎弹窗。

**工作区焦点**：四个工作区（左上 / 预览 / 左下 / 时间轴）在指针按下去时获得焦点，亮起 **1px 描边**（`.ed-pane.focused`，用 `outline` + `outline-offset: -1px`：不占布局，预览的黑画布也压不住它）。工具栏是第五个工作区但全是按钮，点按钮不抢焦点。

**结构树（左下第一个标签页）**：判定线 → 音符 / 事件层 → 5 类事件。双击任意一行把对应的内容放进时间轴（行/层/单条轨/音符轨），行尾还有两个小按钮：

- 判定线行尾的 **＋**：新增一个事件层，**5 条事件轨各自动建一条默认事件**（从开头起、保持到结束，取值全 0）。取值刻意用「中性值」而不是 `LINE_EVENT_DEFAULTS`（那是求值兜底，speed 是 1）—— 多层的同名事件是**相加**的，实测加一层 `speed = 1` 会让判定线速度直接翻倍。
- 事件层行尾的 **✕**：删掉这一层（**至少保留 1 层**，只剩 1 层时按钮置灰）；时间轴上这一层的轨道会一起移除，后面几层的轨道则整体前移一位。
- **没有音符的判定线也会列出「音符」行**（标注「无音符」），双击同样能把空音符轨放进时间轴 —— 结构树是「这张谱面有什么」的全景，缺行会让人以为编辑器读漏了。

**触屏（尤其 iOS）**：整页禁用系统级文字框选与长按「拷贝」气泡（`user-select: none` + `-webkit-touch-callout: none`，输入框单独放回 `user-select: text`），并用 `touch-action: manipulation` 去掉双击缩放 —— iOS 上双击/长按不会再弹出系统选择框。

**第五个工作区：工具栏**（`#ed-workspace-tools`，夹在左下工作区与时间轴之间，与时间轴用一条分界线隔开，背景也自成一块）。里面是**两列，样式完全一致**（同一套按钮尺寸 / 悬停 / 颜色）：

| 列 | 内容 | 说明 |
| --- | --- | --- |
| `#ed-tools` | 鼠标 / 移动 / 添加 / 剪刀 | **模式**：点了会切换当前工具，当前项高亮（`.active`） |
| `#ed-actions` | 撤销 / 重做 / 复制 / 剪切 / 粘贴 / 删除 | **一次性动作**（见 §3）：不可用时变灰，中间用一条细线分成「撤销重做」与「剪贴板」两组 |

分成两列是为了不把「当前处于什么状态」和「点一下做一件事」混在一起；两列用同一套样式，避免看起来像两种控件。

## 2. 时间轴

- **横轴单位是拍**（不是秒），缩放范围 8–320 px/拍（默认初始 6 拍可见）。
- 轨道（`src/editor/tracks.js`）：
  - **音符轨**：一行高 189px，横轴是时间，纵向按 `positionX` 分布；Hold 画成长条（手绘蓝色胶囊 + 头部贴图）。
  - **事件轨**：每类事件一条（X 位移 / Y 位移 / 旋转 / 不透明度 / 速度），行高 42px，事件块按取值画趋势线。
  - 同一事件层的轨道**整组导入并绑定**（一起显隐 / 移动 / 移除）；移除单条用行右侧按钮，移除整组用组标题右键。
- 事件主题色：X `#999999`、Y `#ffd700`、旋转 `#FF1493`、速度 `#1e90ff`、不透明度 `#00FA9A`、音符 `#cfcfcf`。

### 工具：鼠标 / 移动 / 剪刀 / 添加

工具栏有四个工具（`src/editor/main.js` 的 `TOOLS`），切换时 `timeline.setTool()` 只做两件事：改内部工具状态 + 换容器上的触屏策略类（`.tool-pan` / `.tool-scissors` / `.tool-add`，都写在 CSS 里）。

| 工具 | 鼠标 | 触屏 |
| --- | --- | --- |
| **鼠标**（`arrow`） | 下表全部行为：点选 / Ctrl 多选 / 框选 / 拖动改时间与 `positionX` / 刻度尺拖指针；**右键还能直接放置**（音符轨放 Tap、事件轨两点定区间，见下）；**中键拖动 = 平移时间轴**（会吃掉系统级中键行为：Windows 的自动滚动、X11 的粘贴） | 单指拖动 = **框选 / 拖拽**；**双指拖动 = 平移**（按两指中点算，所以两指各自移动也不会甩）；原生滚动被锁定（`touch-action: none`），不然一指下去既滚动又框选 |
| **移动**（`hand`） | 拖动平移时间轴（**已去掉「鼠标靠近边缘自动滚动」**：贴边不再自己滚，要滚就拖或滚轮） | 单指滑动 = **原生横/纵滚动**（`touch-action: pan-x pan-y`）；指针事件不接管触屏，惯性与滚动条都交给浏览器 |
| **剪刀**（`scissors`） | 指针放到事件块 / Hold 上显示**剪切线预览**（跟随刻度吸附），单击即在指针处切成两段 | 触屏不接管（同样锁掉滚动，避免误切） |
| **添加**（`add`） | 时间轴角落的**调色板浮窗**（tap / drag / hold / flick，可任意拖动，位置记忆）；Tap / Drag / Flick 点一下就放下，**Hold 与事件都点两下定首尾**；移动时有**虚影**、**右键（或 Esc）取消** | 触屏同鼠标工具（锁掉滚动，点按就是放置） |

### 添加工具

- **调色板浮窗**：挂在时间轴面板右上角，按住标题栏可拖到任意位置（写进 `localStorage`）；只有四个类型按钮，没有其它参数（长度由两次点击决定）。
- **音符轨**：
  - Tap / Drag / Flick：移动时按指针位置显示虚影（拍 + `positionX`，跟随刻度 / 横向吸附），**点一下**放下一个音符并自动选中。
  - **Hold 与事件一样是两点定首尾**：第一下只记起点（虚影跟着指针拉区间），第二下收尾；两点的 `positionX` 都取起点那一下的值（水平位置不在中途改）。
- **事件轨**：第一次点击定起点，移动时显示区间虚影，第二次点击定终点；两端取值取**本轨道上一个事件的末值**（`previousEndValue`；该轨道前面没有事件时用该类型的缺省值 `x/y = 0`、`rotate = 0`、`alpha = 1`、`speed = 1`），所以接在已有动画后面不会有跳变；默认线性，可在 Event 详情页改缓动。
- **不允许重叠（唯一的例外是 Hold）**：音符要求「时间区间相交 **且** `positionX` 相同」才算冲突（同一时刻不同 X 的双押是合法的）；**只要涉及 Hold 就放行** —— Hold 与别的音符同位置同时刻是常见写法（按住长条时再补一个 Tap / Drag），两份长条叠着也是作者的自由。事件轨则任何区间相交都拒绝，冲突时虚影框变红、状态栏说明原因。Tap 这类零长区间会先按 1e-4 拍撑开再判重叠，否则「同一时刻同一 X 放两个」永远判不出来。
- 新音符会带上 `src` 源对象（按同一线已有音符的键名构造，official 的 `type/time/holdTime` 与 RPE 的 `type/startTime/endTime` 都能填对），将来实现导出时直接可用。

### 鼠标工具的右键放置

鼠标工具下右键不会弹菜单，而是**就地放置**（`rightClickPlace`）：

| 目标 | 行为 |
| --- | --- |
| 音符轨 | 直接放一个 **Tap**（不选类型、没有虚影预览 —— 就是快速补一个单点） |
| 事件轨 | 与添加工具**完全一致**：第一下定起点、移动时有区间虚影、第二下收尾；此时右键的作用是「取消」 |

- 右键与添加工具共用同一套放置代码，所以同样受**吸附**与**不允许重叠**约束，冲突时状态栏给出原因，虚影变红表示这一下放不下去。
- 添加工具下右键 = 取消；鼠标工具下右键 = 放置（事件轨第二次右键即取消那一半未完成的区间）。

### 剪刀：切分语义

切口处的新始末值由**原曲线在那一点的取值**决定：`vCut = start + (end − start) · easingFn(u)`（`u` 为原事件进度）。两段继续用原来的缓动表达，做到与**原曲线完全等价**（不是"相近"）：

| 原缓动 | 切分方式 | 实测最大偏差 |
| --- | --- | --- |
| 预设（如 `#9 In Cubic`） | 用 RPE 自带的 `easingLeft/easingRight` 把原曲线裁到 `[L, x]` 与 `[x, R]`（`makeEasing` 的裁剪本身就是"取值重映射"，两段拼起来恰等于原定义） | **5.6e-17** |
| 带裁剪的预设（`easingLeft/Right` 已非默认） | 同上，切口换算到 `[L, R]` 窗口内的位置 | **1.1e-15** |
| 贝塞尔 | 对三次曲线在 `x=u` 处做 **de Casteljau 分割**（先用牛顿迭代反解参数 `t`），两半各自归一化成新的 `bezierPoints` | **5.3e-7** |

- **Hold** 切成两个音符：时间/时长按切口分，位置取原判定线在该时刻的高度（`rt.heightAt`），两段在切口处首尾相接。⚠️ 玩法上会变成两个 Hold，判定与原来不同 —— 这是"剪开"的固有含义。
- **保持到结束**（哨兵 `endBeat`）的事件也能切：第一段落到切口，第二段继续保持。
- 切口余量按**绝对拍数**判定（1e-3 拍），不用比例 —— 官方谱「从开头起效」的事件起点是 `-31249` 这种哨兵值，用比例会让整段可见范围都算作"离末端太近"，根本切不动（这是实测踩到的坑）。
- 切分是**就地改原事件 + 在事件层里插入第二段**，然后只重建这一条轨的 clip 并选中两个新片段（不重排、不丢视图）。事件数组按 `startBeat` 保持有序。
- 吸附开启时切口会吸到刻度线上，因此**细碎事件（如官谱常见的 0.125 拍小段）在吸附下可能没有落点** —— 关掉吸附或调细刻度即可。
- 剪刀只切**你点的那一条轨**：剪 X 位移不会连 Y 位移一起剪。若该层的 X/Y 原本成对（RPE 的 `xybind` 语义、官方格式的位移更是只有一个数组），剪完就会在纠错里看到一条 **X/Y 位移不成对**（错误级）；要保住绑定就把同一拍的 Y 位移也剪一次。

实现要点：

- 时间轴本体本来就是**原生双向滚动容器**（`overflow: scroll` + spacer 撑出全曲宽度与总高度），所以「触屏滚动」不需要 JS 模拟 —— 只是用 `touch-action` 决定要不要放给浏览器。
- 平移（移动工具拖动 / 鼠标工具中键拖动 / 触屏双指拖动）都是自己改 `scrollLeft/scrollTop`（并同步内部状态重绘）；只有刻度尺拖动还保留贴边滚动（`updateEdgeScroll`）。
- 触屏的「移动工具」完全走浏览器原生滚动，因此**带惯性**；「鼠标工具」下则锁掉，避免同一根手指既滚动又框选。

### 拖动 = 直接改谱面（写回）

拖动不是「只动时间轴视图」，而是**改谱面模型本身**，所以预览、详情页、纠错、将来的导出都立刻跟着变。

| 环节 | 做法 |
| --- | --- |
| 拖动过程中 | 源对象**每帧**跟着改（事件写 `startBeat/endBeat`，音符写 `startBeat/endBeat/positionX`，连源对象 `note.src` 一起写），时间轴实时跟手 |
| 派生数据 | 渲染用的不是源对象：事件要编译成 `{t0,t1,v0,v1,f}` 列表、音符要 `timeSec/durationSec/height`。这些由 `refreshLine()` **局部重编译**（只重算受影响的那条线），拖动中按 **120ms 节流**、松手立刻做一次 |
| 音符时间 | 重排 `chart.notes`、重算 `endTime/duration` 与多押标记（`refreshNotes()`），并让自动判定的游标重新定位（`resyncJudgeCursor`，否则会重复判定/漏判） |
| 通知 | 松手时 `onClipsChanged()` → 左上详情/曲线页刷新、纠错页标脏重扫 |

细节与取舍：

- **起点按「时间轴上的新左边缘」写回**：拖动时用秒做桥（`axis.toSec` → 线内 `secondsToBeat`），因为多条线的 BPM 倍率不同，「线内拍」≠「时间轴上的拍」；时长单独保持，不做逐帧累加，所以怎么拖都不会漂。
- **哨兵值**：`endBeat` 是「保持到结束」哨兵（≥1e6）的事件，拖动**只挪起点**；而起点是「从开头就生效」哨兵（负数，如 −31249）的事件，一旦被拖动就会变成**具体拍值** —— 与你在时间轴上看到的左边缘一致（否则拖完一看又弹回左边）。
- 详情面板改时间/取值、曲线页拖手柄、添加工具放对象、剪刀切分走的都是同一条路：改完源对象后 `refreshLine()` 局部重编译（曲线页连续拖手柄同样是 120ms 节流），所以**四处的改动预览都看得见**。此前只有时间轴自己更新，预览会停在旧动画上。
- 拖到别的线上做重叠**不会拦**，交给纠错页报告（重叠是警告级，见 §5）。

| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5s |
| `R` | 重开 |
| `[` / `]` | 倍速 −/+ 0.25 |
| `N` / `M` | 音符宽度 −/+（与播放器一致，默认 W/8） |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴（见 §3） |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除选中项 |

## 3. 复制 / 剪切 / 粘贴 / 删除 与 撤销 / 重做

时间轴右侧工具栏的**第二列**是编辑操作：撤销 / 重做 / 复制 / 剪切 / 粘贴 / 删除。按钮不可用时会变灰（没选中 → 复制/剪切/删除灰；剪贴板为空 → 粘贴灰；栈空 → 撤销/重做灰），悬停提示会写明「下一条会撤销什么」。

| 操作 | 快捷键 | 行为 |
| --- | --- | --- |
| 复制 | `Ctrl+C` | 把选中项存成**模板**（类型 / 取值 / 缓动 / 时长 / 相对偏移），**不持有原对象**，所以删掉原件也能继续粘贴 |
| 剪切 | `Ctrl+X` | 复制 + 从模型里删掉原对象（一步撤销就能还原） |
| 粘贴 | `Ctrl+V` | **以模板在指针所在的拍新建对象**（不是把同一个对象塞回数组） |
| 删除 | `Delete` / `Backspace` | 从模型里移除选中项（音符会同时从 `rt.notes`、`chart.notes`、源音符列表里移除） |
| 撤销 | `Ctrl+Z` | 回退一步 |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` | 前进一步 |

### 粘贴的语义（模板新建，不是 copy）

- 复制时记住**每条对象相对最早一条的偏移**（时间轴拍）；粘贴时整组**锚定到指针所在的拍**，保持彼此的相对关系（两条相隔 0.125 拍的事件，粘出来还是相隔 0.125 拍）。
- 事件回到它原来的**线 / 层 / 类型**；音符回到原来的线，`type / positionX / above / isFake / speed` 照抄，源对象按目标线的模板重建（导出用得到）。
- 时长按**线内拍**搬运；「保持到结束」的事件粘贴后仍然保持到结束。
- **重叠**：与**有限区间**相交的条目跳过（状态栏报出「跳过 N 条」），但**「保持到结束」的事件不算冲突** —— 否则一层里只要有一条「保持到结束」，它后面任何位置都贴不进去；而渲染器是「后开始的生效」，贴在它后面本来就是有意义的编辑。
- 粘贴完**自动选中新对象**，可以接着拖；整件事一步可撤销。

### 撤销 / 重做的性能取舍

为什么不做「整谱快照」：白复生 AT 是 24 线 / 15.4 万事件，整谱深拷贝一次要几十毫秒、几十 MB，每次操作存一份会立刻吃满内存。

| 只记这些 | 说明 |
| --- | --- |
| 字段改动 | 对象**改动前的字段值**（提交时再取一次改后的，只留真正变了的键）。拖动 3 个事件 = 3 个小拷贝；`note.src` 会跟着一起记（详情面板两处都写） |
| 结构改动 | 往哪个数组加了 / 删了哪个对象（删除时记下原位置，撤销插回原位；重做按时间有序插回） |
| 派生数据 | **一律不存** —— 撤销后按受影响的线跑一次 `refreshLine()` / `refreshNotes()` 重算，再重建那几条轨道的 clip，并按**对象身份**恢复选中（重建后 `trackId#index` 已经变了） |

- 栈深默认 **80 步**（`HISTORY_LIMIT`，`src/editor/history.js`），超出丢最旧的；换谱面时整体清空。
- 「一步」的粒度：一次拖动 = 一步（按下时开记录、松手提交，没真的动过不占栈位）；一次拖曲线的过程 = 一步（第一次实时改动开记录、松手提交）；添加 / 粘贴 / 删除 / 切分各算一步；空操作（没选中就删除、空栈撤销）不占栈位。
- 参与记录的改动点：拖动写回、添加工具放置、剪刀切分、复制 / 剪切 / 粘贴 / 删除、Note 详情、Event 详情、曲线页。
- 撤销/重做会**重新走一遍派生数据重编译**，所以撤销后预览、时间轴、纠错看到的一致（不存在「快照与派生数据不一致」这种坑）。

## 4. 详情面板

三个详情页共用 `src/editor/detail-common.js` 的零部件（行 / 数字框 / 复选 / 下拉 / 拍号解析）。

**多选规则（Note 与 Event 一致）**：所有选中项取值一致就显示该值；只要有一个不同就**留空**并显示「多个值（N 项）」，**不加载默认值**。任何修改都应用到**全部选中项**。

面板按「渲染时的选中项」生效：如果编辑时选中项已经变了，会拒绝这次修改并提示重新操作，绝不会把改动写到别的对象上。

### Note 详情

类型（Tap / Drag / Hold / Flick）、拍、`positionX`、Hold 时长、速度、是否在判定线上方、是否假音符（Fake）。改动同时写到渲染器音符对象与它的源层音符（`note.src`）。

### Event 详情

起始时间（拍）、时长、保持到结束、起始值、结束值、**缓动（两级，见下）**、缓动左/右裁剪（RPE 的 `easingLeft/easingRight`）、linkgroup。

- 官方格式的「从开头就生效」用极大负拍做哨兵，界面显示为「从开头起效（哨兵值）」；「保持到结束」对应哨兵 `endBeat >= 1e6`。
- 官方格式**没有缓动字段**（`docs/04`：官谱只有线性）——官谱里看到的曲线是相邻小线段拼出来的，所以事件本身恒为线性，面板会写明这一句。

### 缓动的两级设置

| 一级：缓动类型 | 二级：具体参数 | 写入模型 |
| --- | --- | --- |
| 线性 | — | `easingType = 1`，清空控制点 |
| 预设缓动 | 缓动编号（`缓动#2 · Out Sine` … `缓动#29 · In Out Elastic`，含 `#6 · In Out Sine`） | `easingType = N`，清空控制点 |
| 贝塞尔 | 4 个控制点 `P1.x/y`、`P2.x/y` | `easingType = 6` + `bezierPoints` |

- 缓动编号名称来自 `docs/02` §5 的 29 种对照表（`EASING_NAMES`）。
- **6 号预设是 In Out Sine**，不是贝塞尔；「是否贝塞尔」取决于有没有 4 个控制点（RPE 里 `bezier` 是独立开关）。`easingLabel()` 与 `makeEasing().isBezier` 都按这条规则判断。

### 事件曲线页

把曲线编辑器从 Event 详情里独立出来，用 **SVG** 实现（`viewBox 0 0 360 240`，浏览器负责缩放；指针坐标用同一比例换算，不需要量尺寸 / DPR / ResizeObserver）：

- 纵轴刻度**固定为「该类事件在整条轨道上的取值范围」**（min~max + 5% 余量），所以切换事件、拖动取值时刻度都不变，便于横向比较；线条颜色 = 该类事件的主题色。
- 手柄：绿 = 起始值、黄 = 结束值、粉 = 贝塞尔控制点 P1/P2，**四个手柄一起画在主图里**。
  这是严谨的：`bezierPoints` 是「进度 0..1 × 进度 0..1」空间的控制点，而主图的时间轴与取值轴都是线性（仿射）映射，仿射变换下贝塞尔曲线仍是贝塞尔曲线，控制点按同一映射走。
- **例外**：起止值相同（如 `0 → 0` 的旋转事件）时取值轴塌缩、y 无法反解，这时退回右上角的单位方格子图编辑。
- 起点在显示窗口之外（哨兵起点 / 哨兵终点 / 跨度几千拍）时：只显示末端 16 拍、横轴改用相对拍，手柄贴左边缘显示。
- **颜色事件不走曲线页**：它的取值是 `[r,g,b]` 三元组，没有单一标量可画（时间轴的趋势线取最大通道只是示意）。选中颜色事件时曲线页改为一行提示，改色去 Event 详情页。

### 扩展（故事板）事件

RPE 的扩展事件**不分事件层**：每条判定线每个键只有一份列表（`line.extended`，RPE 文件里是 `extended.<键>Events`），
因此它们不参与「事件层相加」，结构树里也**单独成组**（不挂在任何事件层下）。

| 键 | 主题色 | 图标 | 编辑方式 |
| --- | --- | --- | --- |
| `scaleX` | `#EEEEEE` | `scale.svg` | 数值（起止值，`1 = 原尺寸`；输入步长 0.05） |
| `scaleY` | `#FFB26B` | `scale.svg` | 同上 |
| `color` | `#66ccff` | `color.svg` | 颜色：预览块 + R/G/B 三行，每行「起始 → 结束」（0–255 整数） |

- **结构树**：每条线一行「扩展事件」组，标签显示事件总数；有未实现的键时额外标「N 个未支持」。组默认折叠，展开后逐键列出。**双击组 = 整组导入并绑定**（与双击事件层同等待遇，组名 `ext:<线号>`）；双击单个叶子 = 只导入那一条轨；未实现的键列在组内但不可导入（点它没有动作）。
- **时间轴**：轨道 id 为 `ev:<线号>:ext:<键>`，`layerIndex` 为 `null`（拖动写回据此走扩展分支：数组取自 `line.extended[键]`，缺数组时按需新建）。颜色块的文案是 `R,G,B → R,G,B`，趋势线取最大通道。
- **渲染**：判定线长度 × `scaleX`、厚度 × `scaleY`（内置 `line.png` 语义）；**`color` 直接决定线色**——设了颜色事件的线不再显示 AP 金 / FC 蓝 / 白，线段两端颜色不同时按线性渐变画满整条线（没有颜色事件的线才回退到判定色）。缺省值取「不改变外观」的一侧（`1 / 1 / 白`），负数或非法缩放回退 1。
- **未实现的键**（`incline / text / paint / gif`）：解析时原样保留在 `line.extendedRaw`，导出时写回，界面上标为「本版本未实现」；解析告警会区分「已渲染」与「保留但不渲染」。
- **纠错**：每个「线 × 扩展键」单独检查（非数值 / 负时长 / 哨兵后面还有事件 / 取值超出常见范围），颜色要求三元组 0–255。
- **项目往返**：`line.extended`（规范事件，含缓动）与 `line.extendedRaw`（未实现键的原数据）都写进 `.pce.zip`，重新打开后两者都在。

## 5. 纠错（左下角「纠错」页）

把「多半是写错了」的数据挑出来，列出位置，点一下就跳到时间轴上那个点。入口是左下工作区的**「纠错」标签页**（标签上带角标：有错误显示红色错误数，只有警告显示黄色警告数，全部通过显示 ✓）。

### 严重程度只有两条标准

| 级别 | 判据 | 例子 |
| --- | --- | --- |
| **错误** | **理论上会影响渲染或导出** | 事件负时长（`compileEventList` 直接丢掉这条事件）、字段非有限（求值失败）、未知音符类型、「保持到结束」后面还有事件（后面那些永远不生效）、Hold 负时长（会导出非法数据）、**X/Y 位移不成对**（换工具/导出会丢事件、错位） |
| **警告** | 渲染与导出都照常，只是位置/数值超出常规或不符合本意 | 越界（画面外、取值超范围）、**重叠**（渲染按「后开始的生效」，导出照写）、零长 Hold、非 Hold 带时长、负拍、数组未排序 |

**越界不等于错**：判定线移出画面、`speed = 0` 让线停住，都是作者真在用的手法（白复生 AT 里就有 752 条 `speed = 0`），所以一律按警告给，只提示不拦。

### 检查项与后果

规则表在 `src/editor/lint.js` 的 `RULES`，共 16 项。「后果」一列写的是**这条数据会让渲染器 / 导出 / 别的工具发生什么**，也是判断级别的依据：

| 规则 | 级别 | 判定 | 可能导致的后果 |
| --- | --- | --- | --- |
| 音符字段非法 | 错误 | 时间 / positionX 不是有限数值 | 这条音符**进不了** `line.rt.notes`（渲染器直接跳过），时间轴上也看不到它；导出写出去就是 `NaN`，别的工具解析会失败 |
| 未知音符类型 | 错误 | 不是 tap / drag / hold / flick | 贴图与判定都查不到这个类型 → 画面里**不显示也不判定**；导出到官方格式会写出非法的 `type` 编号 |
| Hold 负时长 | 错误 | `endBeat < startBeat` | 时长变成负数：渲染器把结尾夹回头部（Hold 退化成单点），导出会写出 `endTime < startTime` / `holdTime < 0` 的非法数据 |
| **X/Y 位移不成对** | 错误 | 同一事件层里 X 位移与 Y 位移的**条数不同**，或条数相同但第 i 条的起止拍对不上 | RPE 的 `xybind` 要求「每个 XEvent 必有等长的 YEvent」，官方格式的位移更是**只有一个数组**（`start/end` = x、`start2/end2` = y，天生成对）。不成对时：RPE 等工具按索引把 X/Y 配成一对 → **多出来的那条被丢掉、后面的全部错位**（x 配上 y 的时间段）；导出到官方格式也无法无损表达。⚠️ 本渲染器把 X/Y 当两条独立数组求值（与 Phira 一致），所以**编辑器里看不出画面异常** —— 这条报的是「换工具/导出会出问题」 |
| 「保持到结束」不在末位 | 错误 | 哨兵 `endBeat` 之后还有事件 | 排在它后面的事件**永远不会生效**（一直被哨兵压着），作者会以为「改了没反应」 |
| 事件负时长 | 错误 | `endBeat < startBeat` | `compileEventList` **整条跳过**这条事件 → 动画里这一段完全缺失，看起来像「事件没写进去」 |
| 事件字段非法 | 错误 | 时间 / 取值不是有限数值 | 求值失败：这条事件被跳过，该时段取的是上一条的值（数值不会崩，但动画与预期不符） |
| 音符重叠 | 警告 | 同一判定线上 **positionX 与所在面（above）都相同** 且时间区间相交（零长音符按 1e-4 拍撑开再判）。**涉及 Hold 的不报**（唯一例外：允许 Hold 与其它音符叠）；两个非 Hold 音符叠在一起才提示 | 两个音符都照常渲染与导出，但**玩法上要同一时刻同一位置打两下**（打不着） |
| 事件重叠 | 警告 | 同一线同一事件类型**跨层合并后**区间相交（拖动把两个事件叠在一起就会命中这条） | 渲染与导出都正常，只是按「**后开始的生效**」—— 前一条的尾段被吃掉，多半不是本意 |
| positionX 超界 | 警告 | `\|positionX\| > 8.889`：内部单位是「官方 X」（1 X = 0.05625 画面宽），8.889 就是画面半宽 | 音符落在画面之外：**看不见也打不到**。作者故意把音符移出画面做演出时，这是正常的 |
| Hold 时长为 0 | 警告 | Hold 的 `endBeat == startBeat`（官谱里 `holdTime` 缺失就是这个情况） | 退化成单点判定（玩家看到的是一个瞬间消失的 Hold） |
| 非 Hold 带时长 | 警告 | Tap / Drag / Flick 的 `endBeat > startBeat` | 渲染与导出都**忽略**这段时长（就是个普通音符）—— 但通常意味着「想写 Hold 却选错了类型」 |
| 音符速度非法 | 警告 | 音符自己的 `speed ≤ 0` | `Y(t) = speed × (height − PJ(t))`：`0` 会让音符**一直贴在判定线上**、负值会让它反向下落。渲染不崩，但落线节奏完全不对 |
| 音符时间为负 | 警告 | `startBeat < 0` | 谱面一开始就已经落线（0 秒处一次性补判）→ 开头会看到一串音符瞬间消失 |
| 事件值越界 | 警告 | 不透明度不在 −1~1、x/y 绝对值超过 10（画面比例单位）、旋转超过 1000 rad、速度绝对值超过 10000 | 不透明度会被夹到 0~1、x/y 只是「跑到画面外」：渲染器不会崩，绝大多数是**单位写错**（例如把 RPE 的 675 直接填进比例单位） |
| 事件未按时间排序 | 警告 | 数组没有按 `startBeat` 升序（RPE 规范要求有序） | 本项目解析后会重排（渲染正常），但**直接读原始 JSON 的工具**会按原顺序处理 → 事件顺序错乱；导出时也会原样写出乱序数据 |

四条**刻意的语义**（都是为了不在真谱面上刷假警告）：

- **零长事件是合法的**：RPE 的瞬时事件就是 `startBeat == endBeat`，渲染器专门处理 `t1 <= t0`，所以事件只在**负**时长时报错；只有 Hold 音符零长才算问题。
- **正/背面分开算**：同一时刻同一 positionX、但一面在判定线上方一面在下方的两个音符**不算重叠**（双面谱常见），避免误报。
- **速度不能拿 0 当错误**：白复生 AT 里有 752 条 `speed = 0`、1 条 `-1.1`，是「判定线停住 / 反向」的正常写法。
- **只做单向位移不报**：某层只有 X 位移（没有 Y 位移）在不绑定时是合法写法，渲染与导出都正常，所以 `X/Y 位移不成对` 只报「两边都有事件却配不上」。

> 编辑器操作会打破配对：剪刀只作用于**一条轨**，剪开 X 位移时同层的 Y 位移不会跟着剪 —— 原本成对的层剪完就会命中这条规则（要在 RPE 里保住绑定，就把同一拍的 Y 位移也剪开）。加位移事件同理：只加 X 就得补一条同长 Y。

### 解析告警：载入时提醒一次

解析告警（`chart.warnings`）说的是「文件里有东西被本编辑器**忽略或丢弃**了」，与纠错规则（扫的是已经进模型的数据）互不覆盖，但现阶段作者也改不了：

- 典型两类：① **未实现的格式特性**（`谱面含扩展事件（已渲染：scaleXEvents；保留但不渲染：inclineEvents）`、`含 *Control 字段（本版本未实现，已忽略）`）—— 这类最容易被误解成「编辑器坏了」；② **脏数据被丢弃/纠正**（未知音符类型、非法时间、BPMList 非法等）。
- 实测两个样本：白复生 AT **0 条**；领土战争 AT **2 条**。
- 处理方式：**载入时提醒一次**（右上角 toast，列前 3 条，9 秒后自动消失，也能点掉），完整列表全部 `console.warn` 打到控制台备查。**不常驻**在任何面板里 —— 缺的功能以后会补，天天挂着的告警只是噪音。
- 谱面总览页显示格式、判定线 / 音符数与时长；改元数据与资源见 §1。

### 阈值是怎么定的

所有「越界」阈值都按**内部规范单位**（`src/core/units.js`），并且用两个真实谱面实测过，让它们在真谱面上**0 命中**：
白复生 AT（official，24 线 / 15.4 万事件）与 领土战争 AT（RPE，24 线 / 8.1 万事件）的实测极值 ——
`|positionX| ≤ 7.49`、`x ∈ [-1.3, 1.3]`、`y ∈ [-2.5, 4.5]`、`|rotate| ≤ 37`、`alpha ∈ [0, 1]`、`speed ∈ [-1.1, 999]`。
阈值再收紧一点就会开始刷假警告，所以 x/y 取 10、rotate 取 1000、speed 取 10000。

`X/Y 位移不成对` 也照真谱面定过口径：两个样本的 **24 个事件层全部成对**（两边都有事件、条数相等、逐条起止拍一致），所以规则只报「两边都有事件却配不上」，`某层只有单向位移` 一律放过。

### 检查频率与性能策略

| 时机 | 行为 |
| --- | --- |
| 载入谱面后 | 自动扫一遍（分片进行），角标立刻有数 |
| 谱面数据变动后 | **防抖 900ms** 后重扫；不在前台也会扫（角标要一直准），只是不重绘列表。连续拖动/连打只会重扫最后一次 |
| 打开「纠错」页 | 若数据是脏的就立刻开扫 |
| 手动「重新检查」 | 无视脏标记，立刻重扫 |

省性能的三个手段：

1. **分片**：扫描本身是生成器（`createLintScan`），每片最多占主线程 8ms，优先走 `requestIdleCallback`（500ms 超时兜底），没有就退回 `setTimeout(0)`。实测白复生 AT 全量 34ms、领土战争 AT 20ms，但被切成 1~5 片，期间时间轴照常拖动与重绘。
2. **按判定线缓存**：每条线算一个 64 位签名（覆盖该线全部音符与事件数值），签名没变的线直接复用上次结果 —— 只改一个音符时第二次扫描 9ms（只剩签名那点开销）。
3. **明细上限**：最多保留 4000 条明细（计数始终准确），列表一次渲染 300 行、可「显示更多」。

### 跳到错误点

点列表里的任一条：

1. 该错误所属的轨道（音符 → `notes:<线号>`；事件 → `ev:<线号>:<层>:<类型>`）**不在时间轴里时会自动加入**（只加这一条，不整组导入），并在状态里说明「已自动加入」；
2. **纵向**滚到那条轨道（`timeline.revealTrack`，把该行居中）；
3. **横向**把指针跳到错误所在秒（用**秒**而不是拍：多条线 BPM 倍率不同时「线内拍」≠ 时间轴上的拍），并让该拍落在可见范围中间；
4. 选中出错的片段 —— 左上会跟着切到 Note / Event 详情，可以直接改。

> 纠错读的是**谱面模型**（`chart.lines[].layers[]` 与 `line.rt.notes`），也就是编辑器写回的那个模型。时间轴拖动、详情面板、曲线页、添加与剪刀的改动都会写回模型并触发重扫（拖动写回见 §2「拖动 = 直接改谱面」）—— 所以把两个事件拖成重叠，松手后这里就会出现一条警告。

## 6. 数据流

```
chart.lines[l].layers[k][key]   ← 唯一真值（解析器产出的源事件对象）
        │
        ├─ tracks.js  makeEventTrack / makeNotesTrack → clip（派生：拍坐标、文案、趋势、缓动函数）
        │        clip.ev 指回源事件对象
        │
        ├─ 拖动 / 详情面板 / 曲线页 / 添加 / 剪刀：改源对象（+ note.src / ev.src）
        │
        ├─ refreshEventClip(track, index, axis) 就地把 clip 的派生字段算回来（不重排、不重建 → 选中状态不丢）
        │        → timeline.redraw() → 画布（时间轴自己）
        │
        └─ refreshLine(chart, lineId, {keys, notes}) 局部重编译**渲染用的**派生数据：
        │     事件 → compileLayers → rt[key]（预览求值用的就是它；缓动函数是编译时抓的引用！）
        │     扩展事件 → compileExtended → rt.extended[键]（数据来自 line.extended，不分层）
        │     音符 → timeSec / durationSec / height（height 依赖速度事件积分）
        ├─ refreshNotes(chart)：音符时间变了 → 结束时间 / 多押 / chart.notes 顺序
        ├─ preview.resyncJudging()：判定游标重新定位（重排后不重复判定、不漏判）
        └─ preview 下一帧自动用新模型渲染（预览、纠错、将来的导出都看得到）
```

要点：

- **改的是源对象**，派生字段（`t0/b0/text/...`）随后就地刷新；事件数组不重排，因此选择不会跳。
- **只改源对象是不够的**：渲染求值读的是 `rt[key]` 里编译出来的 `{t0,t1,v0,v1,f}`（`f` 还是编译那一刻抓的缓动函数引用），音符读的是 `timeSec/durationSec/height`。所以改完必须走一次 `refreshLine()`，否则「时间轴变了、预览没变」。全量 `prepareChart` 在大谱面上要几百毫秒，故只重算受影响的那条线（拖动时按 120ms 节流）。
- 面板改动后会**延后一个任务**再重建 DOM（`setTimeout`，不是 `requestAnimationFrame`——后台标签页里 rAF 会被暂停）。这是为了避免在下拉框自己的 `change` 处理器里同步换掉 DOM 导致的「提示成功但下拉显示旧值」。
- 改动失败 / 选中项变化 / 写进去读不回来时，面板顶部会出现一行红字；**成功时不显示任何提示**。
- **撤销 / 重做走的是同一条收尾路径**（§3）：`history` 反向应用记录（字段值 / 数组增删）→ 按受影响的线 `refreshLine()` / `refreshNotes()` → 重建那几条轨道的 clip → 按对象身份恢复选中。所以撤销之后预览、时间轴、纠错三者一定是一致的。

## 7. 已知缺口

| 项目 | 说明 |
| --- | --- |
| **导出 / 保存** | **已实现**（左上「导出」页）：官谱 zip、RPE zip、内部项目 zip（`.pce.zip`，含全部资源；序列化 + 反序列化）。见 §10「导出」 |
| **导出是有损的** | 官谱格式只有单层、没有缓动：RPE 谱导出成官谱时多层会相加合并、缓动按 12 段折线近似（导出页会列告警）。官方 → RPE 时 alpha 量化到 0–255（Δ≤1/255） |
| **撤销栈的粒度** | 一次拖动 / 一次曲线拖拽各算一步；**没有**「按对象历史」的细粒度回退，也不跨谱面保留 |
| 新增对象 | **音符 / 事件都能在时间轴上直接放**（添加工具；鼠标工具右键也能放），也能**复制 / 剪切 / 粘贴**（粘贴=按模板在指针处新建）；**事件层可以在结构树里新增 / 删除**（至少保留 1 层，新增时 5 条事件轨各带一条默认事件）。还缺：放置后不能立刻指定缓动（要去 Event 详情页改）、没有拖动时的实时长度输入、不能跨谱面粘贴、不能拖动排序事件层 |
| RPE `*Control` | `posControl / alphaControl / sizeControl / skewControl / yControl` **未实现**，解析时只给一条告警（`含 *Control 字段（本版本未实现，已忽略…）`）。它们的缓动字段叫 `easing`（不是 `easingType`），且缓动作用于「以该事件为终点」的区间，实现时需向前平移一格（见 `docs/02` §7） |
| RPE 扩展事件 | **`scaleX / scaleY / color` 已渲染可编辑**（见 §4「扩展（故事板）事件」）；`incline / text / paint / gif` 已解析但未渲染（告警 + 结构树标「本版本未实现」，导出写回） |
| 官方格式缓动 | 官谱没有缓动字段，模型里恒为线性（编辑时的缓动只在内存生效） |
| 拖动写回的粒度 | 拖动过程中派生数据按 120ms 节流重编译（松手立刻补一次），所以大谱面上「拖动时的预览」约 8 次/秒地跟；单个键事件上万条时不会每帧重编译。仍是全量重编译的那一条线，不是逐事件增量 |

| 大谱面性能 | `prepareChart` 仍是全量重编译；40 MB JSON 编辑时不做增量（路线图阶段 4） |
| 纠错的覆盖范围 | 只查**模型内部一致性**：不查音频长度对不上、不查视觉遮挡、不查「官方格式里被解析器丢弃的脏数据」（那些在纠错页顶部的**解析告警**块里，见 §5）。RPE `*Control` 字段未实现，所以它们的缓动错误也查不出来 |

## 10. 导出

左上工作区的「导出」页提供三项，**按用途排序**：内部格式（唯一的保存，强调项）→ RPE → 官谱
（`src/editor/export-tab.js`，打包逻辑在 `src/core/export-package.js`）：

| 选项 | 产物 | 说明 |
| --- | --- | --- |
| 保存项目（内部格式） | `<曲名>.pce.zip` | `project.json` + `info.txt` + **全部资源文件**（音频/曲绘/自定义贴图/打击音）。项目是「下次接着改」的那份，所以资源必须随包走 |
| 导出为 RPE 谱（zip 包） | `<曲名> [RPE].zip` | 同上包结构，谱面换成 RPE 格式（`META` 里写音频/曲绘文件名）；事件层与缓动尽量无损 |

- 有损的地方会在导出页列成告警（例如「缓动折线近似」「alpha 量化」「扩展事件无法表达」），不静默丢弃。

## 11. 项目格式与持久化

**决定**：内存真值使用统一模型（`src/core/model.js`）；磁盘上使用**自有且带版本的项目格式**，
official / RPE 只作为导入与导出的互操作格式。

理由：RPE 并非开放格式；后续的专属功能需要一个能无损容纳它们的格式；直接以 RPE 存盘会在往返中
丢失未实现字段（扩展事件、`*Control`、`attachUI`、`isGif`、`anchor` 等）。

**实现**：`src/core/project.js`（序列化 / 反序列化）+ `src/core/export-package.js`（打包）。
只写「源数据」（拍、取值、缓动编号与参数、贝塞尔控制点），跳过运行时编译产物（`rt`、`easingFn`、
`timeSec`、判定状态），保证重新读入后可完整重编译。往返测试见 `tools/render-tests.mjs` 的
「内部项目格式」一节（逐帧对比误差为 0）。

**元数据与「保存」的语义**：网页不把文件写入磁盘，「编辑」只改内存。唯一的保存动作是导出页的
「保存项目（内部格式）」；官谱 / RPE 导出是有损互操作，不改变未保存状态。

### 11.1 未保存状态、关闭拦截与草稿（已实现）

| 环节 | 实现 |
| --- | --- |
| 脏标记 | `src/editor/autosave.js` 的 `markEdited()`。触发点：`timeline.onClipsChanged`（拖动、添加、剪切、粘贴、删除、详情面板写回）与 `timeline.onModelChanged`（曲线页拖手柄、拖动中的节流写回 —— 这条只重编译、不走 `onClipsChanged`），以及「谱面总览」页的元数据与媒体改动 |
| 状态可见 | 导出标签页角标「未保存」（`topTabs.setBadge(id, {kind:'unsaved'})`；样式在 `editor.css` 的 `.ed-tab-badge.unsaved`：**沿用角标警示色 + 3 秒缓慢闪烁**，`prefers-reduced-motion` 下不闪烁；刻意不做高饱和渐变与加粗，避免像「付费解锁」标记）；首次改动时弹一次 toast：**只讲不保存的后果与保存方式**（「关闭或刷新页面会丢失本次修改；请在「导出」页用「保存项目」写入文件」），不提草稿，避免用户依赖自动保存 |
| 关闭拦截 | `beforeunload` 在 `dirty` 时 `preventDefault()`（原生文案由浏览器决定）；`pagehide` 与 `visibilitychange(hidden)` 补写一次草稿 |
| 清脏 | `markClean()`：载入/恢复新内容时（`preview` 的 `onDocumentLoaded`）。`markSaved()`：**保存项目**成功后，同时删除草稿 |
| 草稿写入 | 改动停止 4 秒（`AUTOSAVE_DEBOUNCE_MS`）后写入，两次写入间隔不小于 15 秒（`AUTOSAVE_MIN_INTERVAL_MS`）；并发调用合并成一次写入 |
| 草稿内容 | 项目格式（无损）JSON → gzip（约 12.7 MB → 1.7 MB）。库 `phichart-editor-drafts`、store `drafts`，记录 `index`（概要，启动只读它）/ `chart`（谱面字节）/ `asset:<名|大小|时间>`（资源 Blob） |
| 资源策略 | 单文件 ≤ 8 MB（`MAX_ASSET_BYTES`）且合计 ≤ 24 MB（`ASSET_BUDGET`）才随草稿保存；音频通常超限，只记名字，恢复后在「谱面总览」页重新上传 |
| 恢复 | 欢迎弹窗顶部的「恢复未保存的草稿」卡片（`welcome.refreshDraftCard()`）：**只有确实存在草稿时才显示**（`draft.peek()` 要求记录带 `savedAt`）；点击走 `autosave.readDraft()` → `preview.loadJson(json, label, files)` → `markEdited()`（恢复后仍是未保存状态）；旁边可「丢弃草稿」 |
| 降级 | 无 IndexedDB（隐私模式、测试桩件）→ 内存后端，仅本次会话有效；写入失败（配额等）→ 停用自动保存并提示一次，脏标记与关闭拦截继续工作 |

**已知限制**：单草稿槽，不保留历史版本；多标签页同时编辑同一草稿时后写覆盖；旧草稿可能属于另一张
谱面（所以恢复入口排在欢迎弹窗最前，并显式提供「丢弃草稿」）。

### 11.2 后续：直接写回原文件

`File System Access`（需安全上下文）：`showSaveFilePicker` / `showDirectoryPicker` 拿到句柄后可
「保存回原文件」并把句柄存入 IndexedDB，重开页面一键恢复（权限需再确认一次）；不支持的浏览器
退回现在的下载方式。
