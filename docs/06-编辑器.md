# 编辑器（阶段 3：编辑 UI）

> 状态：**可用的编辑骨架**。时间轴上的选择 / 拖动 / 参数编辑已经能改到内存模型、并立即反映到预览；
> **导出与保存还没做**（路线图阶段 1、2），所以目前改动只存在于内存里，刷新即丢。

编辑器和播放器是**同一个静态应用的两个入口**：

| 入口 | 文件 | 用途 |
| --- | --- | --- |
| 播放器 | `index.html` | 只播放/查看（渲染器 v1 的原有入口） |
| 编辑器 | `edit.html` | 编辑（本文档描述的对象） |
| 开始页 | `start.html` | 打开项目 / 谱面包、新建项目、内置测试项目（两个入口的共同入口） |

三者共用 `src/core`（模型、解析、计时、缓动）与 `src/render`（Canvas2D 渲染）。

## 1. 界面结构

```
┌──────────────────────── 上半（高度默认 42%） ─────────────────────────┐
│ 左上工作区（宽度可拖）         │ 预览（实时渲染指针所在时刻）            │
│  标签：谱面总览 / Note 详情 /  │  ├ 显示开关：判定线 / 音符 / 多押提示     │
│        Event 详情 / 事件曲线   │  ├ 播放条：播放 / ±5s / 重开 / 回滚 /     │
│                              │  │  背景 / 音频 / 时间 / 倍速 / 性能统计  │
├──────────────────── 上下分隔条（拖拽改比例） ─────────────────────────┤
│ 左下工作区（宽度可拖）  │ 工具栏 │ 时间轴（主工作区）                    │
│  标签：结构树 / 诊断    │        │  工具条：拍号 / 吸附 / 刻度密度 /      │
│                        │        │    横向吸附与线数 / 缩放                │
└──────────────────────────────────────────────────────────────────────┘
```

三个分隔条（`#ed-split-topleft` / `#ed-split-bottomleft` / `#ed-split-main`）的尺寸用 CSS 变量 + `localStorage` 记住（`src/editor/layout.js`）。

## 2. 时间轴

- **横轴单位是拍**（不是秒），缩放范围 8–320 px/拍（默认初始 6 拍可见）。
- 轨道（`src/editor/tracks.js`）：
  - **音符轨**：一行高 189px，横轴是时间，纵向按 `positionX` 分布；Hold 画成长条（手绘蓝色胶囊 + 头部贴图）。
  - **事件轨**：每类事件一条（X 位移 / Y 位移 / 旋转 / 不透明度 / 速度），行高 42px，事件块按取值画趋势线。
  - 同一事件层的轨道**整组导入并绑定**（一起显隐 / 移动 / 移除）；移除单条用行右侧按钮，移除整组用组标题右键。
- 事件主题色：X `#999999`、Y `#ffd700`、旋转 `#FF1493`、速度 `#1e90ff`、不透明度 `#00FA9A`、音符 `#cfcfcf`。

### 鼠标

| 操作 | 行为 |
| --- | --- |
| 左键点选 | 选中该事件块 / 音符（`trackId#index`） |
| Ctrl+左键 | 加入/移出选择 |
| 空白处拖动 | 框选 |
| 拖动已选中项 | 改时间（拍，吸附跟随刻度）+ 音符的 `positionX`（开启横向吸附时对齐刻度线） |
| 指针区域（刻度尺）拖动 | 移动指针 |

选中态：事件块画**内边缘**高亮，音符画**外边缘**高亮。

### 滚轮与触控板

| 输入 | 行为 |
| --- | --- |
| 普通滚轮 / Shift+滚轮 / 横向 `deltaX` | 横向滚动 |
| Ctrl+滚轮 | 纵向滚动 |
| Ctrl+Alt+滚轮 或 触控板捏合 | 缩放（×1.08/步） |

### 快捷键

| 键 | 行为 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5s |
| `R` | 重开 |
| `[` / `]` | 倍速 −/+ 0.25 |
| `N` / `M` | 音符宽度 −/+（与播放器一致，默认 W/8） |

## 3. 详情面板

三个详情页共用 `src/editor/detail-common.js` 的零部件（行 / 数字框 / 复选 / 下拉 / 拍号解析）。

**多选规则（Note 与 Event 一致）**：所有选中项取值一致就显示该值；只要有一个不同就**留空**并显示「多个值（N 项）」，**不加载默认值**。任何修改都应用到**全部选中项**。

面板按「渲染时的选中项」生效：如果编辑时选中项已经变了，会拒绝这次修改并提示重新操作，绝不会把改动写到别的对象上。

### Note 详情

类型（Tap / Drag / Hold / Flick）、拍、`positionX`、Hold 时长、速度、是否在判定线上方、是否假音符（Fake）。改动同时写到渲染器音符对象与它的源层音符（`note.src`）。

### Event 详情

起始时间（拍）、时长、保持到结束、起始值、结束值、**缓动（两级，见下）**、缓动左/右裁剪（RPE 的 `easingLeft/easingRight`）、linkgroup。

- 官方格式的「从开头就生效」用极大负拍做哨兵，界面显示为「从开头起效（哨兵值）」；「保持到结束」对应哨兵 `endBeat >= 1e6`。
- 官方格式**没有缓动字段**（`docs/04`：官谱只有线性）——官谱里看到的曲线是相邻小线段拼出来的，所以事件本身恒为线性，面板会写明这一句。

### 缓动的两级设置

| 一级：缓动类型 | 二级：具体参数 | 写入模型 |
| --- | --- | --- |
| 线性 | — | `easingType = 1`，清空控制点 |
| 预设缓动 | 缓动编号（`缓动#2 · Out Sine` … `缓动#29 · In Out Elastic`，含 `#6 · In Out Sine`） | `easingType = N`，清空控制点 |
| 贝塞尔 | 4 个控制点 `P1.x/y`、`P2.x/y` | `easingType = 6` + `bezierPoints` |

- 缓动编号名称来自 `docs/02` §5 的 29 种对照表（`EASING_NAMES`）。
- **6 号预设是 In Out Sine**，不是贝塞尔；「是否贝塞尔」取决于有没有 4 个控制点（RPE 里 `bezier` 是独立开关）。`easingLabel()` 与 `makeEasing().isBezier` 都按这条规则判断。

### 事件曲线页

把曲线编辑器从 Event 详情里独立出来，用 **SVG** 实现（`viewBox 0 0 360 240`，浏览器负责缩放；指针坐标用同一比例换算，不需要量尺寸 / DPR / ResizeObserver）：

- 纵轴刻度**固定为「该类事件在整条轨道上的取值范围」**（min~max + 5% 余量），所以切换事件、拖动取值时刻度都不变，便于横向比较；线条颜色 = 该类事件的主题色。
- 手柄：绿 = 起始值、黄 = 结束值、粉 = 贝塞尔控制点 P1/P2，**四个手柄一起画在主图里**。
  这是严谨的：`bezierPoints` 是「进度 0..1 × 进度 0..1」空间的控制点，而主图的时间轴与取值轴都是线性（仿射）映射，仿射变换下贝塞尔曲线仍是贝塞尔曲线，控制点按同一映射走。
- **例外**：起止值相同（如 `0 → 0` 的旋转事件）时取值轴塌缩、y 无法反解，这时退回右上角的单位方格子图编辑。
- 起点在显示窗口之外（哨兵起点 / 跨度几千拍）时：只显示末端 16 拍、横轴改用相对拍，手柄贴左边缘显示。

## 4. 数据流

```
chart.lines[l].layers[k][key]   ← 唯一真值（解析器产出的源事件对象）
        │
        ├─ tracks.js  makeEventTrack / makeNotesTrack → clip（派生：拍坐标、文案、趋势、缓动函数）
        │        clip.ev 指回源事件对象
        │
        ├─ 详情面板：改 clip.ev（+ note.src / ev.src）→（可选）刷新派生字段
        │
        └─ refreshEventClip(track, index, axis) 就地把派生字段算回来（不重排、不重建 → 选中状态不丢）
                 → timeline.redraw() → 画布
                 → preview 下一帧自动用新模型渲染
```

要点：

- **改的是源对象**，派生字段（`t0/b0/text/...`）随后就地刷新；事件数组不重排，因此选择不会跳。
- 面板改动后会**延后一个任务**再重建 DOM（`setTimeout`，不是 `requestAnimationFrame`——后台标签页里 rAF 会被暂停）。这是为了避免在下拉框自己的 `change` 处理器里同步换掉 DOM 导致的「提示成功但下拉显示旧值」。
- 改动失败 / 选中项变化 / 写进去读不回来时，面板顶部会出现一行红字；**成功时不显示任何提示**。

## 5. 已知缺口

| 项目 | 说明 |
| --- | --- |
| **导出 / 保存** | 未实现（路线图阶段 1、2）。改动只在内存里，刷新即丢 |
| **撤销栈** | 未实现 |
| 新增对象 | 只能从「结构树」双击事件层整组导入轨道；还不能在时间轴上新建音符 / 事件 |
| RPE `*Control` | `posControl / alphaControl / sizeControl / skewControl / yControl` **未实现**，解析时只给一条告警（`含 *Control 字段（本版本未实现，已忽略…）`）。它们的缓动字段叫 `easing`（不是 `easingType`），且缓动作用于「以该事件为终点」的区间，实现时需向前平移一格（见 `docs/02` §7） |
| RPE 扩展事件 | `textEvents / paintEvents / gifEvents` 等已解析但未渲染（告警提示） |
| 官方格式缓动 | 官谱没有缓动字段，模型里恒为线性（编辑时的缓动只在内存生效） |
| 大谱面性能 | `prepareChart` 仍是全量重编译；40 MB JSON 编辑时不做增量（路线图阶段 4） |

## 6. 开发工具

| 工具 | 用途 |
| --- | --- |
| `启动渲染器.cmd` | 一键起服务器（`tools/dev_server.py`，`Cache-Control: no-store`，默认对局域网开放）并打开开始页 |
| `tools/dev_server.py` | 开发用静态服务器。**必须用它而不是 `python -m http.server`**：后者不发缓存头，浏览器会启发式缓存 ES 模块与谱面 JSON，导致「页面是新的、某个 .js / 谱面还是旧的」这类混搭故障（面板显示旧值、结构树层数对不上、改了没反应）。用法：`python tools/dev_server.py [--host 0.0.0.0] [--port 8099]`，环境变量 `PHICHART_HOST` / `PHICHART_PORT` |
| `node tools/editor-smoke.mjs` | 编辑器无头测试（迷你 DOM + Canvas 桩件）：布局、时间轴、选择与拖动、详情面板、曲线页、性能约定 |
| `node tools/browser-check.mjs` | **真浏览器**自检（Edge/Chrome 无头，两种窗口尺寸）：控件几何与命中测试、缓动下拉真正能改、曲线等比不拉伸、画布位图与显示比例一致；覆盖小测试谱 / 官方大谱（24 线 13.5 万事件）/ RPE 带缓动谱（The Chariot） |
| `node tools/normalize-icons.mjs` | 规范化 `assets/icons/*.svg`（把图形中心对齐到几何中心，避免图标按钮里偏移） |

浏览器自检需要本机有 Edge 或 Chrome；没有就打印一行提示并跳过（不算失败）。

> `packages/` 里的谱面包是第三方资源，**不在版本库里**：缺少时依赖它的用例会自动跳过（判定依据见 `tools/samples.mjs`）——
> `editor-smoke` / `app-smoke` 整份跳过，`render-tests` / `render-smoke` / `browser-check` / `http-smoke` 只跳过示例包那几段。
> 想跑全量：把谱面包放回 `packages/`（目录名与文件名见 `tools/samples.mjs`）。
