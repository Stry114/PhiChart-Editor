# 谱师文档

PhiChart Editor 的制谱器使用指南。面向实际制谱的读者，说明如何打开内容、在时间轴上编辑、检查错误并导出成品。

格式与数学的完整依据见 [Phigros文档.md](Phigros文档.md)；代码结构与开发流程见 [项目文档.md](项目文档.md)。

## 1. 开始使用

### 1.1 启动

在项目根目录启动静态服务器，再打开开始页 `index.html`：

```powershell
启动渲染器.cmd                          # Windows 一键：启动服务器并打开浏览器
python tools/dev_server.py              # 等价的手动方式（默认端口 8099）
python tools/dev_server.py --host 127.0.0.1   # 只允许本机访问
```

必须使用 `tools/dev_server.py`，不要用 `python -m http.server`：后者不发送缓存头，浏览器会启发式缓存 ES 模块与谱面 JSON，容易出现「页面已更新、某个模块还是旧的」这类混搭故障。开发服务器显式发送 `Cache-Control: no-store`。

服务器默认监听 `0.0.0.0`，启动时会列出局域网地址（平板与手机可用同一地址打开）。注意整个项目目录都会对局域网可见，仅在可信网络中开启。

开始页只有两个入口：

| 入口 | 用途 |
| --- | --- |
| 编辑器 | 制谱与实时预览 |
| 播放器 | 只渲染与试听：载入谱面包后自动游玩并计分 |

### 1.2 进入编辑器：先载入内容

进入编辑器后，欢迎弹窗会遮住界面并要求先选择一种方式载入内容。载入前编辑器不可操作，载入后弹窗自动关闭。

| 方式 | 说明 |
| --- | --- |
| 打开文件夹包 | 选择含谱面 JSON、音频与曲绘的目录 |
| 打开 zip 包 | 谱面包 zip，或本编辑器保存的 `.pce.zip` 项目包 |
| 创建新项目 | 填写全部元数据，并上传音频与背景图 |

也可以把包直接拖入窗口，或打开单个谱面 / 项目 JSON（不含资源，可另选音频与曲绘）。

音频与曲绘文件建议直接使用谱面包目录的方式打开，编辑器会自动认领并在导出时一起打包。

### 1.3 保存与自动保存

**网页不把文件写入磁盘，也不上传任何内容**：编辑结果只存在于内存与浏览器本地草稿中。

| 行为 | 说明 |
| --- | --- |
| 保存 | 只有「导出」页的**保存项目（内部格式）**是保存动作，产出 `.pce.zip`（含全部资源文件）。导出官谱 / RPE 供游戏或其它工具使用，属有损互操作，**不算保存** |
| 未保存提示 | 有未保存修改时，「导出」标签页显示闪烁的「未保存」角标；关闭或刷新标签页会被浏览器拦截并提醒（提示文案由浏览器决定） |
| 草稿 | 改动停止约 4 秒后，编辑器把项目格式（无损）gzip 压缩后写入浏览器本地，下次进入时欢迎弹窗提供「恢复未保存的草稿」 |

草稿只是意外关闭时的补救，不能替代保存：它只存在于本机浏览器，清除站点数据即丢失；保存项目成功后会自动删除；音频等大文件不随草稿保存，恢复后可在「谱面总览」页重新上传。

## 2. 界面

```
┌──────────────────────── 上半（高度默认 50%） ─────────────────────────┐
│ 左上工作区（宽度默认 3/5）    │ 预览（实时渲染指针所在时刻）            │
│  谱面总览 / Note 详情 /       │  画布铺满整块                          │
│  Event 详情 / 事件曲线 / 导出 │  播放条：播放 / ±5s / 重开 / 回滚 /      │
│                              │          背景 / 音频 / 时间 / 倍速      │
├──────────────────── 上下分隔条（拖拽改比例） ─────────────────────────┤
│ 左下工作区（默认 1/4）│ 工具栏  │ 时间轴（主工作区）                    │
│  结构树 / 纠错        │ 模式 │ 动作 │ 工具条：拍号 / 吸附 / 刻度密度 /  │
│  （标签带问题数角标） │      │      │   横向吸附与线数 / 缩放           │
└──────────────────────────────────────────────────────────────────────┘
```

三个分隔条可拖拽调整比例，尺寸记在浏览器本地。默认比例：左上 : 右上 = **3 : 2**（详情面板与曲线图需要宽度）、左下 : 右下 = **1 : 3**、上 : 下 = **1 : 1**；窗口过窄时宽度会自动收住，保证预览与时间轴不被挤没。

工作区在指针按下时获得焦点并显示 1px 描边，便于确认键盘操作作用于哪一块。

### 2.1 谱面总览（元数据与资源）

曲名、曲师、谱师、曲绘师、难度、ID、offset 全部可改，改动即时写入模型。

- offset 会同步到播放时钟（`谱面时间 = 音乐时间 − offset`）；
- **包内元数据里的 Offset 也会被读取**：official 的 `info.csv` / `info.txt` 有 `Offset` 列（游戏读的就是它），
  按和其它字段一样的权威顺序仲裁（info.txt > info.csv > 谱面 JSON），单位是**秒**；
- 音频与曲绘可「更换…」；包内缺资源时按钮显示为「上传…」，上传后写入对应元数据字段并登记为包内资源，保存项目或导出 zip 时一起打包；
- 本页**不提供载入按钮**：需要换存档时刷新页面，回到欢迎弹窗重新选择。

### 2.2 结构树

结构树是「这张谱面有什么」的全景视图，最上面是**谱面相机**（谱面级，不属于任何判定线），然后是「判定线 → 音符 / 事件层 / 扩展事件 → 具体事件」。

**交互统一用单击**（部分浏览器里双击不灵）：单击一行 / 一个叶子就是「导入这条轨」，行首的折叠图标负责展开 / 折叠。

| 操作 | 结果 |
| --- | --- |
| 单击判定线行 | 清空时间轴后导入整条线（音符轨 + 各事件层 + 扩展事件） |
| 单击音符行 | 只导入该线的音符轨（没有音符时也会建出一条空音符轨） |
| 单击事件层行 | 把该层的 5 条事件轨整组导入并绑定（一起显隐 / 移动 / 移除）；5 条都还没有事件时会把它们全建出来 |
| 单击事件层里的单条事件行 | 只导入那一条事件轨 |
| 单击扩展事件组 | 把已实现的扩展事件轨（`scaleX` / `scaleY` / `color` / `z` / `theta`）整组导入 |
| 单击扩展事件里的单个键 | 只导入那一条轨 |
| 单击「谱面相机」组 / 某个通道 | 导入相机关键帧轨（`x` / `y` / `z` / `focal`，见 §3.10） |
| 轨道行尾的 ✕ | **删掉这条轨**：清空该键的事件（可撤销），时间轴上那条也一起移除；没有事件时置灰 |
| 判定线行尾的 ＋ | 新增一个事件层，5 条事件轨各带一条默认事件（从开头起、保持到结束） |
| 事件层行尾的 ✕ | 删除该层（**至少保留 1 层**，只剩 1 层时按钮置灰） |

**缺的轨道也能直接加**：事件层里固定列出 5 类事件、扩展事件组里固定列出 5 个已实现键、相机组里固定列出 4 个通道，没有事件的那几条显示「空」。单击「空」的那一行即把它放进时间轴（一条空轨），再用工具栏的**添加**工具在它上面拉出第一条事件即可 —— 以前只有已经有事件的轨道才会列出来，缺的那几条无处可加。

注意：新事件层的默认取值是**中性值全 0**，不是求值缺省值。多层的同名事件是**相加**的，若新层用 `speed = 1` 会让判定线速度翻倍。新增层只多出 5 条可以抓的空事件，不改变现有动画。

没有音符的判定线也会列出「音符」行（标注「无音符」），单击同样能把空音符轨放进时间轴。

顶部两个按钮：**展开全部**（展开到事件层与相机通道，不展开具体事件）与**折叠全部**（只留判定线与相机组那一行）。

未实现的扩展键（`incline` / `text` / `paint` / `gif`）列在「扩展事件」组内并标注「本版本未实现」，不可导入；它们会原样保留并在导出时写回。

### 2.3 工具栏

工具栏分两列，样式一致：左列是**模式**（当前项高亮），右列是**一次性动作**。

| 列 | 内容 |
| --- | --- |
| 模式 | 鼠标 / 移动 / 添加 / 剪刀 |
| 动作 | 撤销 / 重做 ｜ 复制 / 剪切 / 粘贴 / 删除 |

不可用的动作会变灰（未选中时复制 / 剪切 / 删除灰、剪贴板为空时粘贴灰、栈空时撤销 / 重做灰），悬停提示会写明「下一条会撤销什么」。

### 2.4 时间轴

- 横轴单位是**拍**（不是秒），缩放范围 8–320 px/拍，初始约 6 拍可见；
- **音符轨**：行高 189px，纵向按 `positionX` 分布，Hold 画成长条；
- **事件轨**：每类事件一条（X 位移 / Y 位移 / 旋转 / 不透明度 / 速度 / 扩展事件），行高 42px，事件块内画取值趋势线；
- 同一事件层的轨道整组绑定：一起显隐 / 移动 / 移除。移除单条用行右侧按钮，移除整组在组标题上右键；
- 事件主题色：X `#999999`、Y `#ffd700`、旋转 `#FF1493`、速度 `#1e90ff`、不透明度 `#00FA9A`、音符 `#cfcfcf`、X 缩放 `#EEEEEE`、Y 缩放 `#FFB26B`、颜色 `#66ccff`。

## 3. 编辑操作

### 3.1 四种工具

| 工具 | 鼠标 | 触屏 |
| --- | --- | --- |
| **鼠标** | 点选 / Ctrl 多选 / 框选 / 拖动改时间与 `positionX` / 刻度尺拖指针；**右键直接放置**；**中键拖动平移时间轴** | 单指拖动 = 框选或拖拽；**双指拖动 = 平移**；原生滚动被锁定，避免一指下去既滚动又框选 |
| **移动** | 拖动平移时间轴（不含贴边自动滚动） | 单指滑动 = 原生横 / 纵滚动，带惯性 |
| **剪刀** | 指针放到事件块或 Hold 上显示剪切线预览，单击即在指针处切成两段 | 不接管（避免误切） |
| **添加** | 时间轴角落的调色板浮窗选择类型；Tap / Drag / Flick 单击放置，**Hold 与事件两点定首尾**；移动时有虚影，右键或 `Esc` 取消 | 与鼠标工具相同 |

**鼠标工具的右键放置**：音符轨右键直接放一个 Tap；事件轨右键与添加工具完全一致（第一下定起点、第二下收尾，此时第二次右键的作用是取消）。右键放置同样受吸附与重叠约束。

### 3.2 添加工具

调色板浮窗可拖到任意位置（位置记忆）；只有四个类型按钮，没有其它参数（长度由两次点击决定）。

- **笔记轨**：Tap / Drag / Flick 单击放置；Hold 第一下记起点（虚影跟着指针拉区间），第二下收尾；两点的 `positionX` 都取起点那一下的值；
- **事件轨**：第一下定起点、第二下定终点；两端取值取**本轨道上一个事件的末值**，所以接在已有动画后面不会有跳变；默认线性，缓动可在 Event 详情页修改；
- **不允许重叠**：音符要求「时间区间相交**且** `positionX` 相同」才算冲突（同一时刻不同 X 的双押合法）；**只要涉及 Hold 就放行**（按住长条时补一个 Tap / Drag 是常见写法）。事件轨任何区间相交都拒绝。冲突时虚影框变红，状态栏给出原因。

### 3.3 拖动与写回

拖动不是「只动时间轴视图」，而是直接改谱面模型，因此预览、详情页、纠错立刻跟着变。

| 环节 | 行为 |
| --- | --- |
| 拖动过程中 | 源事件 / 音符跟着改，时间轴实时跟手 |
| 派生数据 | 渲染用的是编译后的数据，由 `refreshLine()` 局部重编译（只重算受影响的那条线），拖动中按 120 ms 节流、松手立刻补一次 |
| 音符时间 | 重排音符顺序、重算结束时间与多押标记，并重新定位自动判定游标 |
| 松手 | 通知详情页 / 曲线页刷新，纠错页标脏重扫 |

细节：

- **起点按「时间轴上的新左边缘」写回**，时长单独保持，因此怎么拖都不会漂；
- 「保持到结束」的事件拖动只挪起点；起点是「从开头就生效」哨兵值的事件，一旦被拖动就会变成具体拍值（与你在时间轴上看到的左边缘一致）；
- 拖到别的线上造成重叠不会拦，由纠错页报告。

### 3.4 剪刀：切分语义

切口处的始末值由原曲线在那一点的取值决定，两段继续用原缓动表达，做到与原曲线**完全等价**（不是相近）：

| 原缓动 | 切分方式 |
| --- | --- |
| 预设缓动 | 用缓动裁剪区间把原曲线裁到 `[L, x]` 与 `[x, R]` |
| 已带裁剪的预设 | 同上，切口换算到裁剪窗口内的位置 |
| 贝塞尔 | 对三次曲线做 de Casteljau 分割，两半各自归一化成新的控制点 |

- **Hold** 切成两个音符：时间与时长按切口分，位置取原判定线在该时刻的高度；玩法上会变成两个 Hold，判定与原来不同；
- 「保持到结束」的事件也能切：第一段落到切口，第二段继续保持；
- 切口余量按**绝对拍数**判定，因此官方谱「从开头起效」的哨兵起点事件也能正常切分；
- 切分只改这一条轨：剪 X 位移不会连 Y 位移一起剪。若该层的 X/Y 原本成对，剪完会在纠错里出现一条「X/Y 位移不成对」，要保住绑定就把同一拍的 Y 位移也剪一次。

| 普通滚轮 / Shift+滚轮 / 横向滚动 | 横向滚动 |
| Ctrl+滚轮 | 纵向滚动 |
| Ctrl+Alt+滚轮 或 触控板捏合 | 缩放（×1.08/步） |

| 键 | 行为 |

### 3.6 复制、剪切、粘贴、删除与撤销

| 操作 | 行为 |
| --- | --- |
| 复制 | 把选中项存成**模板**（类型 / 取值 / 缓动 / 时长 / 相对偏移），不持有原对象，删掉原件也能继续粘贴 |
| 剪切 | 复制并从模型里删除原对象（一步撤销即可还原） |
| 粘贴 | **以模板在指针所在的拍新建对象**，不是把同一个对象塞回数组 |
| 删除 | 从模型里移除选中项 |
| 撤销 / 重做 | 回退 / 前进一步，栈深 80 步 |

粘贴细节：

- 记住每条对象相对最早一条的偏移，粘贴时整组锚定到指针所在的拍并保持相对关系；
- 事件回到原来的线 / 层 / 类型；音符回到原来的线，类型与主要属性照抄；
- 「保持到结束」的事件粘贴后仍然保持到结束；
- 与**有限区间**相交的条目会跳过（状态栏报出跳过数量），但「保持到结束」的事件不算冲突，否则一层里只要有一条就无法在其后粘贴；
- 粘贴后自动选中新对象，整件事一步可撤销。

撤销栈只记**改动记录**（字段改动前后的值、数组增删的位置），不存整谱快照；派生数据在撤销后按受影响的线重算。一次拖动、一次曲线拖拽、一次添加 / 粘贴 / 删除 / 切分各算一步；没有实际改动的操作不占栈位。

### 3.7 纠错

纠错页把「多半是写错了」的数据挑出来，列出位置，点击即可跳到时间轴上那一点。标签上的角标显示问题数（有错误显示红色错误数，只有警告显示黄色警告数，全部通过显示 ✓）。

**级别只有两条标准**：

| 级别 | 判据 |
| --- | --- |
| **错误** | 理论上会影响渲染或导出 |
| **警告** | 多半是笔误，但能正常渲染与导出 |

共 18 条规则。下表「后果」列说明这条数据会让渲染器、导出或其它工具发生什么，也是级别的判定依据。

| 规则 | 级别 | 判定 | 后果 |
| --- | --- | --- | --- |
| 音符字段非法 | 错误 | 时间 / `positionX` 不是有限数值 | 该音符进不了渲染列表，时间轴上也看不到；导出会写出 `NaN` |
| 未知音符类型 | 错误 | 不是 tap / drag / hold / flick | 不显示也不判定；导出会写出非法类型编号 |
| Hold 负时长 | 错误 | `endBeat < startBeat` | 渲染时结尾被夹回头部；导出写出非法数据 |
| **X/Y 位移不成对** | 错误 | 同层 X 位移与 Y 位移条数不同，或条数相同但第 i 条起止拍对不上 | RPE 按索引把 X/Y 配对，多出的会被丢掉、后面的全部错位；官方格式的位移天生成对，无法无损表达。本渲染器把 X/Y 当两条独立数组求值，所以编辑器里看不出画面异常——这条报的是「换工具或导出会出问题」 |
| 「保持到结束」不在末位 | 错误 | 哨兵 `endBeat` 之后还有事件 | 排在后面的事件永远不生效，表现为「改了没反应」 |
| 事件负时长 | 错误 | `endBeat < startBeat` | 该事件被整条跳过，动画里这一段完全缺失 |
| 事件字段非法 | 错误 | 时间 / 取值不是有限数值 | 该事件被跳过，该时段取上一条的值 |
| 音符重叠 | 警告 | 同一判定线上 `positionX` 与所在面都相同且时间区间相交（**涉及 Hold 的不报**） | 两个音符照常渲染，但玩法上要在同一时刻同一位置打两下 |
| 事件重叠 | 警告 | 同一线同一事件类型跨层合并后区间相交 | 渲染正常，但按「后开始的生效」，前一条的尾段被吃掉 |
| `positionX` 超界 | 警告 | `\|positionX\| > 8.889`（8.889 即画面半宽） | 音符落在画面外，看不见也打不到（作者刻意移出画面做演出时属正常） |
| Hold 时长为 0 | 警告 | Hold 的 `endBeat == startBeat` | 退化为单点判定 |
| 非 Hold 带时长 | 警告 | Tap / Drag / Flick 的 `endBeat > startBeat` | 时长被忽略，通常意味着「想写 Hold 却选错了类型」 |
| 音符速度非法 | 警告 | 音符自身 `speed ≤ 0` | `0` 会让音符一直贴在判定线上，负值会反向下落 |
| 音符时间为负 | 警告 | `startBeat < 0` | 谱面一开始就已落线，开头出现一串音符瞬间消失 |
| 事件值越界 | 警告 | 不透明度不在 −1~1、x/y 绝对值超过 10、旋转超过 1000 rad、速度绝对值超过 10000、扩展事件的缩放 ≤ 0 或 > 100、`z` 绝对值超过 2 屏高、`theta` 绝对值超过 90° | 渲染不崩，绝大多数是单位写错（例如把 RPE 的 675 直接填进比例单位） |
| 相机取值越界 | 警告 | 相机 `x` / `y` / `z` 的绝对值超过 10 个画面 | 渲染不崩，多半是把长度单位当比例填了（界面里按长度单位填：`1350` = 一画面宽、`900` = 一画面高） |
| 相机焦距非法 | 错误 | 相机 `focal ≤ 0`（或大得离谱） | 渲染时会退回默认视图，相机动画等于没写 |
| 事件未按时间排序 | 警告 | 数组没有按 `startBeat` 升序 | 本项目解析后会重排，但直接读原始 JSON 的工具会按原顺序处理；导出也会原样写出乱序数据 |

**四条刻意的语义**（都是为了不在真实谱面上刷假警告）：

- **零长事件合法**：RPE 的瞬时事件就是 `startBeat == endBeat`，渲染器专门处理，所以事件只在**负**时长时报错；只有 Hold 零长才算问题；
- **正 / 背面分开算**：同一时刻、同一 `positionX`、但一面在判定线上方一面在下方的两个音符不算重叠；
- **速度 0 不是错误**：真实谱面里有大量 `speed = 0`（判定线停住）与少量负值（反向），属正常写法；
- **只做单向位移不报**：某层只有 X 位移、没有 Y 位移在不绑定时是合法写法，因此该规则只报「两边都有事件却配不上」。

检查范围是**模型内部一致性**：不检查音频长度是否对得上、不检查视觉遮挡，也不包括「解析时被丢弃的脏数据」——那部分在纠错页顶部的解析告警块里（见 §3.10）。

### 3.8 事件曲线

曲线页把选中事件的取值曲线画出来，可直接拖手柄改值：

- 纵轴刻度固定为「该类事件在整条轨道上的取值范围」，切换事件或拖动取值时刻度都不变，便于横向比较；线条颜色是该类事件的主题色；
- 手柄：起始值、结束值；缓动为贝塞尔时另加两个控制点手柄；
- 起止值相同导致取值轴塌缩时，退回右上角的单位方格编辑控制点；
- 起点在显示窗口之外（哨兵起点、跨度几千拍）时只显示末端 16 拍，横轴改用相对拍；
- **颜色事件不走曲线页**：它的取值是 `[r,g,b]` 三元组，没有单一标量可画，选中时改为一行提示，改色在 Event 详情页完成。

### 3.9 扩展（故事板）事件

RPE 的扩展事件**不分事件层**：每条判定线每个键只有一份列表，因此不参与事件层相加，结构树里单独成组。组内固定列出下面 5 个已实现键（没有事件的那几个显示「空」，单击即可建出空轨，再用「添加」工具画事件；行尾 ✕ 删掉整条键，可撤销）。

| 键 | 主题色 | 编辑方式 |
| --- | --- | --- |
| `scaleX` | `#EEEEEE` | 数值（起止值，`1 = 原尺寸`） |
| `scaleY` | `#FFB26B` | 数值 |
| `color` | `#66ccff` | 颜色：预览块 + R/G/B 三行，每行「起始 → 结束」，取值 0–255 |
| `z`（Z 轴位移） | `#FF6347` | 长度单位（`900 = 一个画面高`）；正 = 往屏幕内、负 = 往屏幕外 |
| `theta`（下落面倾斜） | `#7A67EE` | 角度（度）；正 = 下落面向屏幕内倾、负 = 向屏幕外倾 |

渲染语义：

- `scaleX` / `scaleY` 分别缩放判定线的长度与厚度；
- `color` **直接决定判定线颜色**：设了颜色事件的线不再显示为金色 / 浅蓝 / 白色，而是完全按事件颜色显示；线段两端颜色不同时按线性渐变画满整条线；
- `z` / `theta` 是**本项目的（伪）3D 扩展**（RPE 本身没有它们，写进 `extended` 后别的工具会忽略）：
  - `z` 让判定线**整条**（连同它上面的音符，含 Hold 的头尾）沿视线方向前后移动：往屏幕内 → 缩小并向画面中心靠拢，往屏幕外 → 放大；线长与线宽一起按透视缩放；
  - `theta` 绕**判定线长轴**旋转「下落面」：音符沿下落方向到线的屏幕距离按 `cosθ` 缩短（判定线旋转时表现为横向偏移），同时按深度缩小、贴图沿下落方向压扁；只影响这条线自己的音符，**子线不继承**；
  - 两者都为 0 时画面与没有这两个事件时逐像素一致；
  - 导出官谱时无法表达（会丢弃并告警）；导出 RPE 时写进 `extended.moveZEvents` / `extended.thetaEvents`，单位与界面一致（长度单位 / 角度制）。
- 未覆盖的时间段取不改变外观的缺省值（缩放 1、颜色白、`z = 0`、`theta = 0`）。

### 3.10 谱面相机（伪 3D 视角）

结构树最上面的「谱面相机」是**谱面级**的关键帧（不属于任何判定线，用法与「可变 BPM」一样按拍给值），四个通道各有主题色：

| 通道 | 主题色 | 编辑方式 | 含义 |
| --- | --- | --- | --- |
| `x` | `#4FC3F7` | 长度单位（`1350 = 一个画面宽`） | 相机横向平移：正 = 相机往右移 → 画面整体往左走 |
| `y` | `#FFD166` | 长度单位（`900 = 一个画面高`） | 相机纵向平移：正 = 相机往上移 → 画面整体往下走 |
| `z` | `#FF6347` | 长度单位（`900 = 一个画面高`） | 沿视线推拉：正 = 往屏幕内 → 画面整体放大、透视更强 |
| `focal` | `#B388FF` | 长度单位（`900 = 默认焦距`） | 焦距：越小透视越强（广角）；画面平面上的东西大小不变 |

- **怎么用**：展开「谱面相机」组 → 单击某个通道导入它的轨道（没有关键帧时就是一条空轨）→ 用「添加」工具在轨道上拉出区间，或用拖动 / Event 详情 / 事件曲线改起止值与缓动；行尾的 ✕ 可以删掉整条通道（可撤销）；
- 相机是**整张谱面**的：`z` / 倾斜事件作用在判定线（物体）上、相机作用在「看的人」上，两者叠加；
- 相机不动（四个通道都为缺省值 `0 / 0 / 0 / 1`）时，画面与完全没有相机时逐像素一致；
- 判定范围里的「轨道判定」会跟着相机走，「垂直判定」则完全忽略相机与 `z` / 倾斜（见 §5.1）；
- 导出：内部项目格式与 RPE（根节点的自有扩展键 `camera`）都能往返；**官谱无法表达**，导出时会丢弃并告警。

### 3.11 解析告警

解析告警说的是「文件里有内容被本编辑器忽略或丢弃了」，与纠错规则（扫的是已经进入模型的数据）互不覆盖。典型两类：

- **未实现的格式特性**：例如「谱面含扩展事件（已渲染：`scaleXEvents`；保留但不渲染：`inclineEvents`）」「含 `*Control` 字段（本版本未实现，已忽略）」；
- **脏数据被丢弃或纠正**：未知音符类型、非法时间、`BPMList` 非法等。

处理方式：**载入时提醒一次**（右上角提示条，列出前 3 条，9 秒后自动消失，也可以手动关闭），完整列表打到浏览器控制台备查。解析告警不常驻在任何面板里。

## 4. 导出

「导出」页提供三项，按用途排序：

| 选项 | 产物 | 说明 |
| --- | --- | --- |
| 保存项目（内部格式） | `<曲名>.pce.zip` | `project.json` + `info.txt` + **全部资源文件**（音频 / 曲绘 / 自定义贴图 / 打击音）。这是「下次接着改」的那份，资源随包走 |
| 导出为 RPE 谱（zip 包） | `<曲名> [RPE].zip` | 同上包结构，谱面换成 RPE 格式；事件层与缓动尽量无损 |
| 导出为官谱（zip 包） | `<曲名> [official].zip` | `<曲名>.json`（formatVersion 3）+ `info.txt` + 音频 + 曲绘，解压即是一个谱面包 |

- **反序列化**：`.pce.zip` 直接拖进编辑器（或「打开项目文件…」）即可，包内资源按元数据与 `info.txt` 自动认领；也支持单文件 `.pce.json`（不含资源，可另选音频 / 曲绘一起打开）。打开后可照常导出成官谱或 RPE；
- 官谱的硬约束（事件列表非空、哨兵值、首尾相接、`bpm > 0`）由导出器主动保证；
- RPE 侧保留未实现的扩展事件与 `*Control` 等字段，导出时原样写回；
- 有损之处会在导出页列成告警（例如「缓动折线近似」「alpha 量化」「扩展事件无法表达」），不会静默丢弃。

导出到官谱时注意：

- 官谱**只有单层、没有缓动字段**，多层事件会被相加合并为单层，缓动按折线近似；
- 扩展事件、父子判定线、假音符、自定义线材质等官谱无法表达的字段会被丢弃并列入告警。

## 5. 播放与预览

预览区画布铺满整块工作区，底部播放条提供播放 / 暂停、±5 秒、重开、自动回滚、背景与音频开关、当前时间、倍速与性能统计。

- 播放中指针会随机时间轴滚动；拖动时间轴刻度尺或指针即可定位到任意时刻；
- 音符宽度、多押提示等显示项在代码中默认全开，需要时通过预览选项控制。

**播放器页面**（`player.html`）提供完整的观看体验：自动游玩并计分、触屏游玩模式与真全屏。播放中屏幕上只有左上角的暂停键与计分 HUD，其余都在暂停页里。

**暂停页**覆盖画面，**不显示任何文字**，主层只有一排纯图标按钮（无外框、无背景）：

| 图标 | 作用 |
| --- | --- |
| 打开 | 进入「打开」页：打开文件夹包 / 打开 zip 谱包（也可把包拖进页面） |
| 重开 | 回到 0 秒并立刻开始 |
| 自动游玩 | 开关。开启 = 自动游玩；关闭 = 触屏判定（仅触屏设备，桌面端置灰） |
| 全屏 | 打开 / 退出全屏 |
| 设置 | 进入「设置」页 |
| 继续 | 从暂停处继续（第一次播放即从 0 秒开始） |

图标含义可用鼠标悬停查看（浏览器提示）。「设置」页收录全部设置项与谱面信息：触屏游玩开关、判定范围、全屏、倍速、音符宽度、显示开关（多押提示 / 判定线 / 音符）、播放进度、谱面信息与解析告警；「打开」页只有两个大图标入口与一个「只选谱面 JSON」链接。两个二级页面都有左上角的返回键回到主层。

**触屏游玩模式**（仅玩家输入；桌面端只有自动游玩）：

| 项 | 规则 |
| --- | --- |
| 判定范围 | 三档可选（记忆在浏览器里，换谱面也保留）：**垂直判定**（默认）只有落在音符所在那条列里的点击、或经过它的滑动才算命中 —— 完全忽略相机与 `z` / 倾斜；**轨道判定**跟着画面走：音符被相机 / `z` / 倾斜画到哪里，判定带就在哪里；**全屏判定**点屏幕任意位置都算。判定带**两边各 80% 音符宽**（总宽 = 音符宽的 160%），沿下落方向两端无限延伸（越过判定线另一侧也算） |
| 多指 | 每个触摸只判一个 Tap / Hold，双押 / 多押必须多指；空点不扣分、不消耗音符。手指之间互不影响：一根按在暂停键上、或已经判过别的音符，都不会拖累其它手指 |
| Tap | ±0.08 / ±0.18 s 判 Perfect / Good，超过 ±0.22 s 判 Miss |
| Hold | 头部按下时机决定 Perfect / Good（无 Bad）；持续时间内**判定范围里只要有任一根手指按着**就算没断（**允许换手**，也可以换到刚判过别的音符的手指上）；断连不超过 **80 ms** 迅速接上仍不算断。**提前松手**：松在「尾部 − min(时长 × 30%, 1 拍)」之后算按完（记头部等级），松得更早才是 Miss。**短于半拍的 Hold 不设断连概念**：头部点中之后随便什么时候松手都算按完。没点到的 Hold 正常不透明下落、尾部过线后淡出；按住后又断连判 Miss 的才显示为半透明 |
| Drag | 判定窗口 **±0.08 s**（项目口径）：窗口内有手指按在垂直判定范围里即 Perfect，全程没有手指则 Miss。**音效**：提前判定（手指早就在带里）时等音符真的落线再响，落后判定才立刻响 |
| Flick | **必须有一次真实滑动**：窗口 **±0.08 s** 内、位移 ≥ **16 px**（且距上次上报 ≤ 250 ms）的滑动线段与判定范围相交即 Perfect —— 不要求滑动起点在范围内，一次滑动可以同时点亮多个 Flick；纯点击 / 按住不动不算。音效同 Drag：提前判定的等落线再响 |

暂停后再点「继续」从暂停处继续（时钟停在原地）；要重来用「重开」。

## 6. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 「页面是新的、某个模块还是旧的」 | 用了不发缓存头的静态服务器。改用 `tools/dev_server.py` |
| 载入后编辑器仍不可操作 | 欢迎弹窗未关闭：选择一种载入方式，或载入成功后弹窗会自动关闭 |
| 谱面打开后提示「扩展事件保留但不渲染」 | 该谱面使用了本版本未实现的扩展键（`incline` / `text` / `paint` / `gif`），数据会原样保留并在导出时写回 |
| 新增事件层后判定线速度变快 | 新层的默认事件取值参与了多层相加。把该层的 `speed` 事件改为 0（中性值） |
| 细碎事件剪不动 | 吸附开启时切口会吸到刻度线上。关掉吸附或调细刻度密度 |
| 导出的官谱丢东西 | 官谱无法表达事件层、缓动、扩展事件、父子线、假音符等。查看导出页的告警逐条确认 |
| 关闭页面时提示未保存 | 有未保存修改。在「导出」页用「保存项目」写入 `.pce.zip` |

## 7. 名词表

| 名词 | 含义 |
| --- | --- |
| 判定线 | 音符下落的目标线；位置、旋转、透明度、下落速度随时间变化 |
| 音符 | Tap / Drag / Hold / Flick 四种 |
| 事件层 | 同一判定线的多组事件；多层同名事件的取值**相加** |
| 事件块 | 时间轴上的一个事件区间 |
| 扩展事件 | 不分层的判定线附加事件（缩放 `scaleX`/`scaleY`、颜色 `color`、Z 轴位移 `z`、下落面倾斜 `theta`，以及未实现的倾斜 / 文本等） |

| 谱面包 | 谱面 JSON + 音频 + 曲绘（+ 可选元数据与自定义资源） |
| 项目文件 | 本编辑器保存的 `.pce.zip`，无损保存模型与全部资源 |
| 速度 | 音符下落速度，单位 Y/s；`1 Y = 0.6` 画面高 |
| 物量 | 参与计分的音符数量，不计假音符 |
